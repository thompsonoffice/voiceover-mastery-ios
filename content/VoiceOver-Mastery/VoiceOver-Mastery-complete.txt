README
============================================================

Welcome to VoiceOver Mastery: The Complete Apple Guide, a book in SRTS: Screen Reader Training Suite.

This is a plain-text, screen-reader-friendly guide to Apple's built-in screen reader, VoiceOver, on every Apple platform that includes it: iPhone, iPad, Mac, Apple Watch, Apple TV, and Apple Vision Pro.

It is written for blind and low-vision users who want to go from turning VoiceOver on for the first time to using it as a power user. You do not need to be technical. If a term is new, the first chapter that uses it explains it.

This copy is a complete first edition, written in November 2026 for Hunter Thompson / Thompson Office (thompsonoffice.itch.io). It is not an official Apple manual. Apple's own user guides remain the authority when a setting or gesture changes after this book is published.


HOW THIS BOOK IS ORGANIZED
The files are plain UTF-8 text. There are no tables and no steps that depend on seeing the screen. Gestures and key commands are written in words, such as "two-finger double tap" or "VO-Space bar."

Start here:

- README.txt: this file.
- CONTENTS.txt: the full list of parts and chapters, in order.
- INDEX.txt: an alphabetical list of topics, gestures, and settings, with chapter numbers.
- VoiceOver-Mastery-complete.txt: every chapter in one searchable file.

The chapters also live in folders, one part per platform, plus an opening part and a closing part for apps and practice:

- 00-About
- 01-iPhone
- 02-iPad
- 03-Mac
- 04-Apple-Watch
- 05-Apple-TV
- 06-Vision-Pro
- 07-Apps-and-Practice

If you like to search, open the combined file and search for a gesture, app, or setting. If you like to study in order, start with Part 0, then complete the iPhone part even if your main device is something else. iPhone is where this book teaches the shared ideas: the VoiceOver cursor, the rotor, typing styles, Screen Curtain, and braille. Later parts tell you what is the same and what changes on each platform.


HOW A CHAPTER IS SET UP
Every chapter uses the same headings, in this order:

- Overview
- What you'll learn
- The teaching sections and numbered steps
- Practice exercise
- Quick reference summary
- Sources

Numbered steps are written with one action per step, so they are easy to follow by ear or on a braille display.


WHICH SOFTWARE THIS EDITION COVERS
This edition was researched in November 2026.

- iPhone and iPad chapters target iOS 26 and iPadOS 26, using Apple's iPhone User Guide and iPad User Guide VoiceOver sections. Where a feature depends on a specific iPhone or iPad model, the chapter says so.
- Mac chapters are based on Apple's VoiceOver User Guide for Mac, as published when this book was written. At that time, Apple's unversioned VoiceOver User Guide was labeled for macOS 27. Commands can vary by macOS version and by keyboard. If a command does not work, use Keyboard Help (VO-K) or check VoiceOver Utility on your Mac.
- Apple Watch, Apple TV, and Apple Vision Pro chapters are based on Apple's current user guides for those products as of the same date. Those platforms change, and some gestures are easy to customize. When this book is less certain, the chapter says so instead of inventing a command.

Apple sometimes publishes newer features in an unversioned online guide before, or after, a numbered system release. This book does not treat preview or next-generation features as if they were already standard on iOS 26. See Chapter 7.3 for a list of accuracy notes.


HOW TO USE THIS BOOK WITH VOICEOVER
On iPhone or iPad:

1. Open the Files app, or any app you use to read plain-text files.
2. Select this README or the combined file, then double-tap to open it.
3. Set the VoiceOver rotor to Lines, Words, or Headings, then swipe up or down to move.
4. Or use a two-finger swipe up to hear a file from the top, and a two-finger tap to pause.

On Mac:

1. Open a chapter in TextEdit, TextEdit-style editors, or any text reader you already use with VoiceOver.
2. Use VO-A to read from the current position, or VO-B to read from the top.
3. Press Control to pause or resume speech.

On a braille display, these are ordinary text files. Heading lines use equal signs and short all-caps titles so they stand out in braille and in speech.


A FEW SAFETY HABITS
Learn these early. They are covered in detail later, but they can get you out of trouble on day one.

On iPhone or iPad, if VoiceOver speech seems to have stopped, try a three-finger double tap. That mutes or unmutes speech. If the screen seems dead but the phone is still making sounds, try a three-finger triple tap. That turns Screen Curtain on or off. If Zoom is also on, those gestures need one extra tap.

Set up the Accessibility Shortcut so you can turn VoiceOver on or off by triple-clicking the side button or the Home button. Ask Siri to turn VoiceOver on or off if you get stuck.

VoiceOver Recognition, Live Recognition, Magnifier Detection Mode, and third-party seeing apps can be useful. They can also be wrong. Apple says VoiceOver Recognition should not be relied on in situations where you could be harmed, in high-risk situations, for navigation, or for medical diagnosis or treatment. This book agrees.

OVERVIEW
This chapter explains how to move through the book, how each chapter is built, and how to practice safely. You can read it once, then jump to the part for your device.

VoiceOver is Apple's built-in screen reader. A screen reader speaks, or sends to a braille display, what is on the screen and what you can do with it. On Apple devices the screen reader is called VoiceOver. The idea is the same on iPhone, iPad, Mac, Apple Watch, Apple TV, and Apple Vision Pro. The way you touch, type, or pinch is not the same on every device.

This book is part of SRTS: Screen Reader Training Suite. It is written in plain text so it works well with VoiceOver, other screen readers, and braille displays.


WHAT YOU'LL LEARN
- How the folders and the combined file work.
- How every chapter is structured.
- Which part to read first.
- How to practice a new gesture without changing your device settings.
- What this edition covers, and what it does not invent.


CHOOSE A WAY TO READ
There are three good ways to use this book.

If you are new to VoiceOver, read in order. Start with this part, then complete the iPhone chapters even if you mostly use an iPad or a Mac. The iPhone part is the longest because it teaches the shared vocabulary.

If you already use VoiceOver on one device and want another, go to that platform's part first. Each later part tells you what is already covered on iPhone and what is different.

If you need one fact, open CONTENTS.txt, INDEX.txt, or VoiceOver-Mastery-complete.txt and search. Searching the combined file is often the fastest way to find a gesture or a Settings path.


HOW TO FOLLOW A STEP
A typical step looks like this:

1. Go to the Settings app.
2. Select Accessibility, then double-tap to open it.
3. Select VoiceOver, then double-tap.

"Select" means move the VoiceOver cursor to that item so VoiceOver speaks it. On iPhone and iPad, you can tap the item, or swipe right or left until you hear it. "Double-tap" means tap twice quickly with one finger to activate the selected item. You can double-tap anywhere on the screen, not only on the item itself, as long as the item is selected.

When a Settings path is written on one line, such as Settings > Accessibility > VoiceOver, it means open Settings, open Accessibility, then open VoiceOver, using that same select-and-double-tap pattern.

Key commands on Mac, and on a keyboard connected to iPhone, iPad, Apple TV, or Vision Pro, use the VoiceOver modifier. This book writes that modifier as VO. By default, VO means either the Caps Lock key, or the Control and Option keys pressed together. So "VO-Space bar" means hold the VoiceOver modifier and press the Space bar.


PRACTICE SAFELY
On iPhone, iPad, and Apple Vision Pro, Apple includes a VoiceOver Practice area. Gestures you perform there are described, but they do not act on your device. Use that area when you are learning a new tap or swipe.

On Mac, Keyboard Help does a similar job for keys and for trackpad gestures. Press VO-K to turn Keyboard Help on or off. Keys and commands are spoken, but they are not performed.

This book includes a short practice exercise in every chapter. Skip an exercise if it asks you to change a setting you do not want to change. You can come back to it later.


WHAT THIS BOOK WILL NOT DO
It will not invent a gesture, rotor item, or keyboard command that was not found in Apple's official documentation at the time of writing. If a feature is unclear, or if it varies by model or system version in a way this book could not confirm, the chapter says so.

It is not a complete manual for every app. Built-in apps such as Safari, Phone, Messages, Mail, Maps, Camera, and Magnifier are covered where Apple documents VoiceOver behavior. Third-party apps are listed honestly in Part 7, with the reminder that apps change.

It is not a substitute for your clinic, your vocational rehab program, or Apple Support when something is wrong with a device.


PRACTICE EXERCISE
1. Open CONTENTS.txt.
2. Move through the headings until you hear the part for your main device.
3. Open that part's first chapter, or stay with Chapter 0.2 if you want the big picture first.
4. If you are on iPhone or iPad, also add VoiceOver Practice to your mental map: Settings > Accessibility > VoiceOver > VoiceOver Practice.


QUICK REFERENCE SUMMARY
- Read in order if you are new. Search the combined file if you need one fact.
- Every chapter has the same headings, including a practice exercise and sources.
- "Select, then double-tap" is the basic iPhone and iPad action.
- VO means the VoiceOver modifier: Caps Lock, or Control and Option together.
- Use VoiceOver Practice or Keyboard Help when learning something new.
- This book cites Apple docs and does not invent commands.

Chapter 0.2. How VoiceOver Fits Together Across Apple Devices
============================================================

OVERVIEW
VoiceOver is one product idea with several different bodies. If you learn the idea once, each new Apple device is easier. This chapter is a map, not a full lesson. The later parts teach the details.

The shared idea is this: VoiceOver speaks, or presents in braille, the item that has focus. That item is often called the VoiceOver cursor. You move the cursor to hear what is there. You perform a separate action to activate it. You can also jump by type of item, using a tool called the rotor, and you can change how much VoiceOver says.


WHAT YOU'LL LEARN
- The ideas that stay the same on every Apple platform.
- Which input method each device uses.
- Where this book puts each platform.
- Which features are shared, and which are not.


THE SHARED IDEAS
The VoiceOver cursor is the item VoiceOver is on. On a touchscreen, you move it by touching an item, or by swiping to the next or previous item. On a Mac keyboard, you usually press VO and the arrow keys. On Apple TV, you use the remote. On Apple Vision Pro, you use hand pinches and your view.

Activate means "do the thing this item does," such as opening an app or turning a switch on. On iPhone and iPad, the usual activate gesture is a double tap. On a Mac keyboard, it is usually VO-Space bar. On Apple TV, it is pressing the clickpad center or touch surface. On Vision Pro, Apple documents a left index pinch or a right ring pinch.

The rotor is a list of settings and navigation types you can cycle through, then move with a second gesture. On iPhone, iPad, Apple Watch, and the Apple TV remote, you often rotate two fingers as if you were turning a dial. On a Mac keyboard, Apple documents VO-U to open the rotor, and other commands to turn it. On Vision Pro, the rotor uses pinch combinations, not a two-finger dial on a glass screen.

Speech can be paused, muted, sped up, or slowed down. A feature called Screen Curtain turns the display off for privacy while VoiceOver keeps working. The exact gesture or command for Screen Curtain is not the same on every device, so do not assume the iPhone habit will work everywhere.

Braille is available on the platforms Apple documents for refreshable braille displays, and iPhone, iPad, and Vision Pro also have ways to type braille on a screen or in a view. Details belong in the braille chapters, not here.


HOW EACH DEVICE IS CONTROLLED
iPhone and iPad are the closest cousins. Most VoiceOver gestures are the same: swipe to move, double-tap to activate, two-finger rotation for the rotor, three-finger swipes to scroll, and a two-finger scrub (a "z" shape) to go back or dismiss. iPad adds a larger screen, a Dock, and, on many models, a stronger external keyboard and windowed work. Hardware also differs: some iPads have a Home button, some unlock with Face ID, and some use Touch ID on the top button.

Mac is keyboard-first. You can also use a trackpad with a set of VoiceOver gestures that will feel familiar if you already use iPhone. You customize almost everything in an app called VoiceOver Utility, which you can open with VO-Fn-F8 when VoiceOver is on.

Apple Watch is a small VoiceOver surface plus the Digital Crown and the side button. Many iPhone habits still work: explore with one finger, swipe to move, double-tap to activate, rotate two fingers for the rotor, and scrub with two fingers to go back. The Digital Crown can also be used for navigation.

Apple TV is controlled with the Siri Remote or Apple TV Remote, not with a large touchscreen. VoiceOver has two modes, called navigation mode and exploration mode, and a rotor you open on the clickpad or touch surface.

Apple Vision Pro uses look-and-pinch gestures. The names sound new, such as "left index pinch" or "left ring modifier with right index pinch," but many actions map to ideas you already know: next, previous, activate, Magic Tap, mute, Item Chooser, Quick Settings, and the rotor. This book lists only gestures found in Apple's Vision Pro User Guide. You can also review every assigned command on the device in Settings > Accessibility > VoiceOver > Commands > All Commands.


A SIMPLE LEARNING PATH
1. Get VoiceOver on, and set an Accessibility Shortcut or an equivalent way to turn it off.
2. Learn to move, activate, go back, and pause speech.
3. Learn the rotor and one or two typing methods.
4. Learn Home, app switching, and Control Center or the closest equivalent.
5. Learn Safari or web navigation if you browse, then mail, messages, and settings.
6. Add braille, a keyboard, or Live Recognition when you need them.
7. When you pick up a second Apple device, read that device's part and practice only what is different.

Chapter 7.2 turns this into a longer practice plan.


PRACTICE EXERCISE
1. Name your main Apple device, and one other Apple device you might use.
2. Open CONTENTS.txt and find the part for each.
3. If you are brand new, do not skip the first seven iPhone chapters. They teach move, activate, read, mute, Screen Curtain, system gestures, and the rotor.


QUICK REFERENCE SUMMARY
- VoiceOver always has a cursor, an activate action, speech or braille output, and usually a rotor.
- iPhone and iPad share most gestures.
- Mac is keyboard-first, with optional trackpad gestures and VoiceOver Utility.
- Apple Watch adds the Digital Crown and a smaller set of rotor items.
- Apple TV uses a remote and two VoiceOver modes.
- Vision Pro uses pinch gestures. Confirm them in the device's Commands list if a gesture fails.
- Later parts of this book are organized by platform and tell you what is shared.

Part 1. iPhone (iOS)
Chapter 1.1. Getting Started with VoiceOver on iPhone
============================================================

OVERVIEW
VoiceOver is a gesture-based screen reader built into iPhone. When it is on, iPhone speaks the name of the item your finger is on, including icons and text. It can also send that information to a braille display. You use VoiceOver gestures to move to another item and to activate an item, such as a button or a link.

This matters: VoiceOver changes the gestures you use to control iPhone. After you turn it on, a single tap no longer opens things the way it did before. That is expected. This chapter gets VoiceOver on, and gives you a safe way to turn it off again.

This edition targets iOS 26, using Apple's iPhone User Guide. Some steps differ on iPhone models with Face ID and on iPhone models with a Home button, such as iPhone SE.


WHAT YOU'LL LEARN
- What happens when VoiceOver is on.
- How to turn VoiceOver on or off in Settings, with Siri, with Control Center, and with the Accessibility Shortcut.
- Why you should set the Accessibility Shortcut before you need it.
- What VoiceOver does when a new screen appears.


WHAT VOICEOVER DOES
When you go to a new screen, VoiceOver plays a sound, then selects and speaks the first item on the screen. That item is typically in the top-left corner.

VoiceOver also tells you when the screen changes between landscape and portrait, when the screen becomes dimmed or locked, and what is active on the Lock Screen when you wake iPhone.

You can customize the speaking voice, the speaking rate, and how much detail you hear. Those settings are covered in later chapters. First, get comfortable turning VoiceOver on and off.


TURN VOICEOVER ON OR OFF IN SETTINGS
If VoiceOver is currently off, you can use ordinary iPhone taps for this path.

1. Open the Settings app.
2. Open Accessibility.
3. Open VoiceOver.
4. Turn VoiceOver on.

If VoiceOver is already on, use VoiceOver gestures:

1. Go to the Settings app.
2. Select Accessibility, then double-tap.
3. Select VoiceOver, then double-tap.
4. Select the VoiceOver switch, then double-tap to turn it on or off.

To turn VoiceOver on or off, Apple also documents these other methods: use Control Center if you have added VoiceOver there, use the Accessibility Shortcut if you have set it up for VoiceOver, or ask Siri something like "Turn on VoiceOver" or "Turn off VoiceOver."

Siri knows when VoiceOver is on and often reads more information back to you than appears on the screen. You can also use VoiceOver to read what Siri shows on the screen.


SET THE ACCESSIBILITY SHORTCUT
The Accessibility Shortcut lets you triple-click a button to turn VoiceOver on or off. Set this up while you can still get around comfortably. It is one of the best safety nets you can have.

1. Go to Settings > Accessibility > Accessibility Shortcut.
2. Select VoiceOver so it is included in the shortcut.
3. If you include only VoiceOver, a triple-click turns VoiceOver on or off immediately.
4. If you include more than one feature, a triple-click opens a list. Select the feature you want, then double-tap.

To use the shortcut:

1. Triple-click the side button on an iPhone with Face ID.
2. Or, on iPhone SE, triple-click the Home button.

If iPhone does not notice your triple-click, you can slow down the click speed in the side button or Home button settings. Apple's Accessibility Shortcut page points to those button settings.

On supported iPhone models, you can also press the Action button for an accessibility feature you choose, or use Back Tap to double-tap or triple-tap the back of iPhone. Those options are set in Settings and are described in Apple's iPhone User Guide. Siri and Control Center remain useful backups.


ADD VOICEOVER TO CONTROL CENTER
You can add VoiceOver to Control Center for quick access. Apple's current iPhone User Guide describes it this way:

1. Open Control Center.
2. Select the control in the top-left corner that lets you change Control Center, then double-tap if VoiceOver is on.
3. Select Add a Control at the bottom of the screen, then double-tap.
4. Find VoiceOver in the list of controls. Accessibility controls may be grouped in categories such as vision. Select VoiceOver, then double-tap to add it.

The exact Control Center layout can vary by iOS version. If the steps above do not match what you hear, search Settings for Control Center and add VoiceOver from there, or ask Siri to open VoiceOver settings.


PRACTICE EXERCISE
1. Set the Accessibility Shortcut to include VoiceOver, if you have not already.
2. Ask Siri to turn VoiceOver on, then ask Siri to turn it off, so you know that path works.
3. Turn VoiceOver on again, then use the Accessibility Shortcut once so you can feel the triple-click.
4. Leave VoiceOver on if you are continuing with the next chapters, or off if you want a break.


QUICK REFERENCE SUMMARY
- VoiceOver speaks the item under your finger and changes iPhone gestures while it is on.
- Turn it on or off in Settings > Accessibility > VoiceOver.
- You can also use Siri, Control Center, or the Accessibility Shortcut.
- Triple-click the side button (Face ID) or the Home button (iPhone SE) for the shortcut.
- Set that shortcut before you get stuck.
- A new screen plays a sound and speaks the first item, usually at the top left.

Chapter 1.2. The VoiceOver Tutorial and Practice Area
============================================================

OVERVIEW
Apple gives you two built-in ways to learn VoiceOver on iPhone without guessing. The VoiceOver Tutorial is an interactive lesson. The VoiceOver Practice area lets you try gestures and hear what they do, without performing the action on your iPhone.

Use both. The tutorial gives you a guided start. The practice area is the place to return whenever a later chapter introduces a new gesture.


WHAT YOU'LL LEARN
- How to start the VoiceOver Tutorial.
- How to open and leave VoiceOver Practice.
- How to make taps, double taps, and swipes more reliable.
- Which gestures Apple suggests you practice first.


OPEN THE VOICEOVER TUTORIAL
With VoiceOver already on:

1. Go to Settings > Accessibility > VoiceOver.
2. Select VoiceOver Tutorial, then double-tap to start.

Follow the tutorial's own spoken instructions. When you finish, you can return to this book and keep going in order.


OPEN VOICEOVER PRACTICE
1. Go to Settings > Accessibility > VoiceOver.
2. If VoiceOver is off, turn it on.
3. Select VoiceOver Practice, then double-tap to start.
4. Try gestures with one, two, three, and four fingers. Apple specifically lists: tap, double tap, triple tap, and swipe left, right, up, or down.
5. When you finish, select Done, then double-tap to exit.

While you are in the practice area, a gesture should be described rather than carried out. That is the point. You can try a three-finger swipe or a two-finger double tap without opening Control Center or taking a photo.


MAKE GESTURES MORE RELIABLE
Apple's advice is practical, and it solves many "this isn't working" moments.

If a gesture does not work, try a quicker movement, especially for a double tap or a swipe. To swipe, brush the screen quickly with your finger or fingers. For best results with multifinger gestures, touch the screen with some space between your fingers.

You can use different techniques for the same gesture. A two-finger tap can be two fingers on one hand, one finger on each hand, or both thumbs. There is no single correct hand position. Use what is comfortable and repeatable for you.

A split-tap is a useful alternative to "select, then double-tap." Touch and hold an item with one finger, then tap the screen with another finger. That activates the item you are holding.


PRACTICE EXERCISE
1. Open VoiceOver Practice.
2. Practice a one-finger swipe right and a one-finger swipe left until VoiceOver consistently describes those gestures.
3. Practice a one-finger double tap. Make it quick.
4. Practice a two-finger tap and a two-finger swipe up.
5. Select Done, then double-tap to exit.


QUICK REFERENCE SUMMARY
- VoiceOver Tutorial is in Settings > Accessibility > VoiceOver.
- VoiceOver Practice is in the same place. Gestures there are described, not performed.
- Practice tap, double tap, triple tap, and swipes with one to four fingers.
- If a gesture fails, try a quicker movement and, for multifinger gestures, more space between fingers.
- A split-tap is: hold with one finger, tap with another.

Chapter 1.3. Core Gestures
============================================================

OVERVIEW
This chapter is the heart of iPhone VoiceOver. When VoiceOver is on, the usual touchscreen gestures do different things, and extra gestures let you move around the screen and control items. VoiceOver gestures include two-finger, three-finger, and four-finger taps and swipes.

Learn a small set well before you try to memorize every gesture Apple documents. If you can explore, move to the next item, go back, activate, pause speech, and scroll, you can already use most apps. The next chapters add reading commands, VoiceOver controls such as mute and Screen Curtain, and system gestures for Home and Control Center.

Practice these in VoiceOver Practice first, then try them on the Home Screen.


WHAT YOU'LL LEARN
- How to explore the screen by touch.
- How to move to the next or previous item.
- How to activate an item, use a split-tap, and do a long press.
- How to go back with a two-finger scrub.
- How to scroll pages and jump to the first or last item.
- How grouped navigation changes two-finger swipes.


EXPLORE BY TOUCH
To explore the screen, drag your finger over it. VoiceOver speaks the name of each item you touch. This is the most natural way to learn a new screen. You can also tap an item once to select it and hear its name.

Exploring by touch does not activate the item. Activation takes a separate gesture, usually a double tap.


MOVE IN ORDER
You can also move through items in order, from top to bottom and left to right.

1. Swipe right with one finger to select the next item.
2. Swipe left with one finger to select the previous item.

These swipes are quick flicks, not slow drags. If nothing happens, try a shorter, faster swipe.


ACTIVATE, LONG PRESS, AND SPLIT-TAP
1. Tap an item once to select it, or swipe until you hear it.
2. Double-tap with one finger to activate it. You can double-tap anywhere on the screen.

A double tap is what opens an app, follows a link, turns a switch on or off, or presses a button.

Apple also documents these related gestures:

- Triple tap: touch and hold, also called a long press, on the selected item.
- Split-tap: touch and hold an item with one finger, then tap the screen with another finger. This activates the held item and is often faster than lifting your finger and double-tapping.
- Two-finger double tap: start or stop the current action. Examples Apple gives are play or pause music or a video, take a photo in Camera, start or stop a recording, and start or stop the stopwatch. This gesture is often called Magic Tap. Chapter 1.4 comes back to it.
- Two-finger double tap and hold: edit the selected item's label to make it easier to find. Chapter 1.17 covers custom labels.


GO BACK OR DISMISS WITH A TWO-FINGER SCRUB
To dismiss an alert or return to the previous screen, do a two-finger scrub. Move two fingers back and forth three times quickly, making a "z" shape.

This gesture is worth practicing until it is automatic. It closes many pop-up menus and takes you back one screen in a lot of apps.


SCROLL A PAGE
Scrolling with VoiceOver uses three fingers, and the direction can feel backward at first. You are moving the page, not moving a finger toward the content you want.

- Three-finger swipe down scrolls up one page.
- Three-finger swipe up scrolls down one page.
- Three-finger swipe right scrolls left one page.
- Three-finger swipe left scrolls right one page.

On the Home Screen, three-finger swipes left or right move between Home Screen pages.


JUMP TO THE FIRST OR LAST ITEM
- Four-finger tap near the top of the screen selects the first item on the screen.
- Four-finger tap near the bottom of the screen selects the last item on the screen.

These are shortcuts for long screens, such as a Settings list or a long article.


MOVE INTO AND OUT OF A GROUP
If you use grouped navigation, some items are collected into a group. Apple documents these gestures:

- Two-finger swipe right moves into a group of items.
- Two-finger swipe left moves out of a group of items.

You choose Flat or Grouped navigation in Settings > Accessibility > VoiceOver > Navigation Style. In Flat navigation, next and previous move through each item in order. In Grouped navigation, you move among items and groups, and you use those two-finger swipes to enter or leave a group. Chapter 1.16 returns to this setting.


ADJUST A SLIDER
1. Select the slider with a tap or a swipe.
2. Swipe up or down with one finger to change the value.

Or:

1. Select the slider.
2. Double-tap and hold until you hear three rising tones.
3. Drag the slider.

The second method is an example of a passthrough gesture, which Chapter 1.6 explains more fully.


REACHABILITY, IF YOUR IPHONE SUPPORTS IT
Apple documents a gesture that lowers the top half of the screen: swipe up from the bottom of the screen with one finger, then, without lifting your finger, swipe down. This is meant to bring items nearer the bottom of a tall iPhone. If the gesture does nothing on your model, you can ignore it.


PRACTICE EXERCISE
Do this first in VoiceOver Practice, then on the Home Screen.

1. Drag your finger slowly across the screen and listen to each item.
2. Swipe right until you hear a familiar app, then swipe left back to a previous app.
3. Select an app you are willing to open, then double-tap to open it.
4. Do a two-finger scrub to go back, or use the Home gesture from Chapter 1.7 if you already know it.
5. On the Home Screen, practice a three-finger swipe left or right to change pages.
6. Try a four-finger tap near the top, then a four-finger tap near the bottom.


QUICK REFERENCE SUMMARY
- Drag a finger to explore. A single tap selects and speaks an item.
- Swipe right for the next item. Swipe left for the previous item.
- Double-tap to activate. Split-tap if you prefer: hold with one finger, tap with another.
- Triple tap is a long press.
- Two-finger scrub (a "z") dismisses or goes back.
- Three-finger swipes scroll. The swipe direction is opposite the page movement.
- Four-finger tap at the top jumps to the first item. At the bottom, it jumps to the last item.
- Two-finger swipe right enters a group. Two-finger swipe left leaves a group, when grouped navigation is on.

OVERVIEW
Most iPhone work is a loop: find an item, make sure it is selected, then activate it. This short chapter slows that loop down, then adds Magic Tap, which starts or stops the current action with a two-finger double tap.

If Chapter 1.3 already feels comfortable, you can treat this as practice and clarification.


WHAT YOU'LL LEARN
- The difference between touching, selecting, and activating.
- How to confirm what is selected before you double-tap.
- How split-tap and Magic Tap fit into daily use.
- How to start or stop common actions without hunting for a button.


TOUCH, SELECT, AND ACTIVATE
Touching the screen tells VoiceOver to speak whatever is under your finger. If you lift your finger after a simple tap, that item stays selected. The VoiceOver cursor is now on that item.

Selecting is not the same as activating. If you tap Messages once, VoiceOver says "Messages" (and usually that it is a button or an app). Messages does not open yet. A double tap opens it.

If you double-tap and the wrong thing opens, the cursor was on a different item than you thought. Try this recovery:

1. Pause. A two-finger tap pauses speech if VoiceOver is still talking.
2. Tap once on the item you want, or swipe until you hear its name.
3. Listen to the full label, including hints such as "button," "switch," or "heading."
4. Double-tap only after you hear the item you want.

You can double-tap anywhere. VoiceOver activates the selected item, not necessarily the spot you tapped the second time. That is helpful, because you do not have to hit a small target twice.


SPLIT-TAP IN DAILY USE
Split-tap is often faster when you are already exploring by touch.

1. Keep your finger on the item you want.
2. Tap the screen with a second finger.

The held item is activated. This is useful on keyboards, in long lists, and anywhere you do not want to lose your place.


MAGIC TAP, OR TWO-FINGER DOUBLE TAP
Apple documents a two-finger double tap as the way to start or stop the current action. Examples include:

- Play or pause music or a video.
- Take a photo in Camera.
- Start or stop a recording.
- Start or stop the stopwatch.

People often call this Magic Tap. In Settings > Accessibility > VoiceOver > Commands, Apple also documents a Magic Tap setting that can pause or play media when no other action is available.

Because Magic Tap is context-dependent, it may take a photo in Camera, answer or end a call in Phone, or pause a song in Music. If you are not sure what "the current action" is, use a named onscreen button instead.

Chapter 1.18 covers the Phone app, where a two-finger double tap answers or ends a call.


PRACTICE EXERCISE
1. On the Home Screen, tap an app once and listen. Do not open it yet.
2. Swipe right or left to a neighboring app, then swipe back.
3. Open one app with a double tap, then go back.
4. Open a different app with a split-tap.
5. If you have music or a podcast ready, start playback with its play button, then use a two-finger double tap to pause and to resume.


QUICK REFERENCE SUMMARY
- Tap or touch to hear and select. Double-tap to activate.
- You can double-tap anywhere once the correct item is selected.
- Split-tap: hold the item, tap with a second finger.
- Two-finger double tap (Magic Tap) starts or stops the current action, such as play/pause or taking a photo.
- If the wrong thing activates, select again and listen before the next double tap.

Chapter 1.5. Reading, Scrolling, and the Item Chooser
============================================================

OVERVIEW
Once you can move and activate, you need ways to hear more than one item at a time, and ways to jump when a screen is crowded. This chapter covers reading gestures, the three-finger tap for extra information, scrolling (reviewed briefly), and the Item Chooser.

The Item Chooser is a list of items on the current screen. You can search it or move through it, then jump straight to an item. It is one of the most useful power-user tools on a busy screen.


WHAT YOU'LL LEARN
- How to hear the whole screen, or the screen from the selected item.
- How to pause and resume speech.
- How to hear extra information about the selected item.
- How to scroll, and how that differs from reading.
- How to open, use, and dismiss the Item Chooser.


READ A SCREEN
Apple documents these reading gestures:

- Two-finger swipe up speaks the entire screen from the top.
- Two-finger swipe down speaks the entire screen from the selected item.
- Two-finger tap pauses or continues speaking.

If you want VoiceOver to read a page or an email out loud, move to where you want to start, then use a two-finger swipe down. Use a two-finger tap to pause. Another two-finger tap continues.

These reading gestures are not the same as scrolling. Reading speaks items that are on the current screen, in order. If more content is off-screen, scroll first, then read again, or keep using next-item swipes after you scroll.


HEAR EXTRA INFORMATION
A three-finger tap speaks additional information, such as the position within a list or whether text is selected. Try it in Settings, in Mail, or in a list of messages. It is a quick way to get your bearings without leaving the item you are on.


SCROLL, REVIEWED
Use three-finger swipes to move to another page of content:

- Three-finger swipe down scrolls up one page.
- Three-finger swipe up scrolls down one page.
- Three-finger swipe right scrolls left one page.
- Three-finger swipe left scrolls right one page.

If a swipe seems to do nothing, you may already be at the end of the content, or the screen may not be a scrolling screen. VoiceOver often plays a sound when you cannot move farther in a direction.


OPEN THE ITEM CHOOSER
1. Do a two-finger triple tap to open the Item Chooser.
2. Find the item you want, using any of the methods Apple documents:
   - Type in the search field to filter the list by name.
   - Swipe right or left to move through the list alphabetically.
   - Tap the table index on the right of the list and swipe up or down.
   - If you use handwriting, you can write the name of an item.
   - If you use Braille Screen Input and you are not entering text, you can type to search for an item.
3. Double-tap an item to jump to it.
4. To dismiss the Item Chooser without making a selection, do a two-finger scrub (move two fingers back and forth three times quickly, making a "z").

The Item Chooser is especially helpful in Settings, on webpages with many links, and in apps with a lot of toolbars and buttons. If you know the first few letters of a button name, search is often faster than swiping through the whole screen.


PRACTICE EXERCISE
1. Open Settings.
2. Use a two-finger swipe up to hear the screen from the top. Pause with a two-finger tap when you have heard enough.
3. Select an item in the middle of the screen, then use a two-finger swipe down to read from there.
4. Try a three-finger tap and listen for position information.
5. Open the Item Chooser with a two-finger triple tap, type or swipe to Accessibility, then double-tap to jump there.
6. If you opened the chooser by mistake, dismiss it with a two-finger scrub.


QUICK REFERENCE SUMMARY
- Two-finger swipe up: read from the top of the screen.
- Two-finger swipe down: read from the selected item.
- Two-finger tap: pause or continue speech.
- Three-finger tap: extra information, such as list position or selection.
- Three-finger swipes scroll pages.
- Two-finger triple tap opens the Item Chooser. Search or browse, then double-tap. Scrub to cancel.

Chapter 1.6. Gestures That Control VoiceOver
============================================================

OVERVIEW
Some gestures do not open apps. They control VoiceOver itself. These are the ones to learn before you ever think speech has "died" or the screen has "gone black."

This chapter covers mute, Screen Curtain, passthrough gestures for standard (non-VoiceOver) gestures, Quick Settings, and the Live Recognition shortcut. It also reminds you what changes if Zoom is on at the same time as VoiceOver.


WHAT YOU'LL LEARN
- How to mute and unmute VoiceOver speech.
- What Screen Curtain is, and how to turn it on or off.
- How those two gestures change when Zoom is also on.
- How to perform a standard iPhone gesture while VoiceOver is on.
- How to open Quick Settings.
- How to start or stop Live Recognition.


MUTE OR UNMUTE SPEECH
Three-finger double tap mutes or unmutes VoiceOver.

Muted speech is not the same as VoiceOver being off. VoiceOver is still on. Gestures still work. Sound effects may still play. You just will not hear spoken output until you unmute, or until you use a braille display.

If both VoiceOver and Zoom are turned on, Apple says to use a three-finger triple tap to mute or unmute, instead of a three-finger double tap.


TURN SCREEN CURTAIN ON OR OFF
Screen Curtain turns the display off while iPhone stays active. VoiceOver keeps working. The screen looks black, as if the phone were off, which is useful for privacy and can help battery life. Apple's iPhone User Guide describes it as a way to keep the screen off when you do not need to see it, and a separate Apple Support article notes that you might use it when checking something private in a public place.

To turn Screen Curtain on or off, use a three-finger triple tap. If both VoiceOver and Zoom are on, use a three-finger quadruple tap.

If a sighted person thinks your iPhone is powered off, but you can still hear VoiceOver or feel haptic responses, check Screen Curtain first.

You can still capture screenshots while Screen Curtain is enabled, according to Apple's Screen Curtain support article. If you share a screenshot, remember that the screen contents were still active.


PERFORM A STANDARD GESTURE (PASSTHROUGH)
Sometimes you need a gesture the way it works when VoiceOver is off, such as dragging a control with one finger.

1. Select the item if the gesture applies to an item, such as a slider.
2. Double-tap and hold your finger on the screen until you hear three rising tones.
3. Make the standard gesture.
4. When you lift your finger, VoiceOver gestures resume.

Apple's example: to drag a volume slider with your finger instead of swiping up and down, select the slider, double-tap and hold, wait for the three tones, then slide left or right.


OPEN QUICK SETTINGS
A two-finger quadruple tap opens VoiceOver Quick Settings. This is a short list of VoiceOver options you can change from anywhere, without digging through Settings.

You can choose which items appear, and in what order, in Settings > Accessibility > VoiceOver > Quick Settings. Chapter 1.17 returns to that customization.


START OR STOP LIVE RECOGNITION
A four-finger triple tap starts or stops Live Recognition, which can describe scenes from the camera and, depending on your settings and model, other visual information around you. Chapter 1.21 covers Live Recognition in full, including Apple's warning not to rely on it for safety, navigation, or medical use.

If a four-finger triple tap does nothing, you may have started and immediately stopped it, or your fingers may have been too close together. Try it again in VoiceOver Practice first, then on the Home Screen.


PRACTICE EXERCISE
Use VoiceOver Practice for mute and Screen Curtain if you want a completely safe rehearsal, then try them on the Home Screen so you know the real result.

1. Do a three-finger double tap to mute speech, then again to unmute. (Use a three-finger triple tap if Zoom is also on.)
2. Do a three-finger triple tap to turn Screen Curtain on. Confirm that VoiceOver still speaks when you touch the screen. Turn Screen Curtain off with the same gesture. (Use a three-finger quadruple tap if Zoom is also on.)
3. Open Quick Settings with a two-finger quadruple tap, look around, then scrub to dismiss if needed.


QUICK REFERENCE SUMMARY
- Three-finger double tap: mute or unmute speech. If Zoom is also on, use a three-finger triple tap.
- Three-finger triple tap: Screen Curtain on or off. If Zoom is also on, use a three-finger quadruple tap.
- Screen Curtain turns the display off. iPhone and VoiceOver stay active.
- Double-tap and hold until three rising tones, then perform a standard gesture.
- Two-finger quadruple tap: Quick Settings.
- Four-finger triple tap: start or stop Live Recognition.

UNLOCK IPHONE
On an iPhone with Face ID:

1. Wake iPhone and glance at it, if Face ID is enabled.
2. Drag up from the bottom edge of the screen until you feel a vibration or hear two rising tones.

On an iPhone with Touch ID, such as iPhone SE:

1. Press the Home button using the finger you registered with Touch ID.

If iPhone prompts you for a passcode, enter it. To avoid having the passcode spoken as you type it, Apple says you can enter it silently using handwriting mode or onscreen braille. Those methods are taught in Chapters 1.11 and 1.12.


GO TO THE HOME SCREEN
On an iPhone with Face ID:

1. Drag one finger up from the bottom edge of the screen until you feel a vibration or hear two rising tones.
2. Lift your finger.

On an iPhone with a Home button, press the Home button.

Notice that the Face ID Home gesture is the same motion as unlocking: a slow drag up from the bottom until the two rising tones or a vibration, then lift.


SWITCH APPS WITH A FOUR-FINGER SWIPE
Swipe right or left with four fingers to cycle through the open apps. This is often the fastest way to jump between two or three apps you are already using.


USE THE APP SWITCHER
To open the App Switcher on an iPhone with Face ID, drag one finger up from the bottom edge of the screen until you feel the second vibration or hear three tones, then lift your finger.

On an iPhone with a Home button, double-click the Home button.

Then:

1. Swipe left or right until the app you want is selected.
2. Double-tap to open the app.

The difference between going Home and opening the App Switcher, on Face ID iPhones, is how far you drag and whether you wait for the second vibration or the third tone before you lift.


OPEN CONTROL CENTER
On an iPhone with Face ID, drag one finger down from the top edge of the screen until you feel a vibration or hear the second tone.

On all iPhone models, you can also do either of the following:

- Tap any item in the status bar, then swipe up with three fingers.
- Touch and hold the bottom of the screen until you hear a tone, then swipe up.

To dismiss Control Center, do a two-finger scrub (a "z" with two fingers, three times quickly).


VIEW NOTIFICATIONS
On an iPhone with Face ID, drag one finger down from the top edge of the screen until you feel the second vibration or hear the third tone.

On all iPhone models, you can also do either of the following:

- Tap any item in the status bar, then swipe down with three fingers.
- Touch and hold the top of the screen until you hear a tone, then swipe down.

To dismiss the notifications screen, do a two-finger scrub.

The Face ID gesture for Control Center and the Face ID gesture for notifications both start at the top edge. Control Center is the earlier stop (vibration or second tone). Notifications are the later stop (second vibration or third tone). If you overshoot, scrub and try again, moving more slowly and listening for the tones.


SPEAK STATUS BAR INFORMATION
1. Tap the status bar at the top of the screen.
2. Swipe left or right to hear the time, battery state, Wi-Fi signal strength, and more.


PRACTICE EXERCISE
1. Go to the Home Screen using the method for your iPhone model.
2. Open an app, then use a four-finger swipe to return to a previous app, if you have more than one app open.
3. Open the App Switcher, swipe through your open apps, and double-tap one to open it.
4. Open Control Center, listen to a few controls, then scrub to dismiss it.
5. Open notifications, then scrub to dismiss them.
6. Tap the status bar and swipe through time, battery, and connectivity.

- Two-finger scrub dismisses Control Center and notifications.

============================================================
VOICEOVER MASTERY: THE COMPLETE APPLE GUIDE
A book in SRTS: Screen Reader Training Suite
Part 1. iPhone (iOS)
Chapter 1.8. The Rotor
============================================================

OVERVIEW
The rotor is one of the most important VoiceOver tools. It is like a virtual dial on the screen. You turn it to choose a setting, then swipe up or down to use that setting.

You can use the rotor to change VoiceOver volume or speaking rate, jump from one heading or link to the next, choose a typing mode, start Braille Screen Input or handwriting, and more. The available settings depend on what you are doing. Typing Mode, for example, appears when a keyboard is present.

This chapter teaches you how to use the rotor. The next chapter covers choosing which items appear on it and in what order.


WHAT YOU'LL LEARN
- How to turn the rotor and choose a setting.
- How to use a setting with one-finger swipes up or down.
- Which rotor options Apple documents for navigating, typing, and speech.
- Why the rotor list changes from screen to screen.


TURN THE ROTOR
1. With VoiceOver on, rotate two fingers on the screen as if you are turning a dial.
2. If you prefer, use one finger on each hand: drag up with one finger and drag down with the other at the same time.
3. VoiceOver speaks the rotor setting. Keep rotating to hear more settings.
4. Stop rotating, and lift your fingers, when you hear the setting you want.

Apple's shorter rotor article says to lift your fingers to choose an option. The User Guide says to stop rotating when you hear the setting you want. Both describe the same idea: finish the turn when you hear the option, then use it.


USE THE SELECTED ROTOR SETTING
Swipe up or down with one finger to use the setting.

What "use" means depends on the setting:

- If the setting is a navigation type, such as Headings or Links, swipe down to move to the next heading or link, and swipe up to move to the previous one.
- If the setting is Speaking Rate or Volume, swipe up or down to increase or decrease the value.
- If the setting is Typing Mode, swipe up or down to cycle among Standard Typing, Touch Typing, and Direct Touch Typing, when those modes are available.

Apple's gesture list states it this way: a swipe up moves to the previous item or increases the value, depending on the rotor setting, and a swipe down moves to the next item or decreases the value.


NAVIGATION OPTIONS
Apple's "About the VoiceOver rotor" article lists many navigation options. With these, a one-finger flick down moves to the next match, and a flick up moves to the previous match.

For reviewing text as you type, or in a document:

- Characters: move and hear one character at a time.
- Words: move and hear one word at a time.
- Lines: move and hear one line at a time.

For the structure of a page or screen:

- Containers: move from one onscreen container to the next. Apple's examples are the Dock and the Home Screen.
- Headings: move from one heading to the next. Apple suggests trying this in Settings areas that are organized with headings.
- Landmarks: move among banners, navigation, and buttons in HTML content, such as a webpage or HTML email.
- Same Item: move to the next item of the same kind. Apple suggests trying this with the links in Safari search results.
- Vertical Navigation: move up or down with one-finger vertical flicks. Apple suggests trying this on the Home Screen.
- Static Text: move from one line of static HTML text to the next. Static text is the main text on the page, not links or button names.

For links:

- Links: all links.
- Visited Links: links you have already opened.
- Non-visited Links: links you have not opened yet.
- In-Page Links: links that jump to another place on the same webpage.

Other page elements:

- Tables: move the VoiceOver cursor to the start of a table on a webpage.
- Lists: move to the start of a list on a webpage.
- Buttons: move from button to button in HTML content.
- Form Controls: move among buttons and menus in a form.
- Text Fields: move from one text field to the next in HTML content.
- Search Fields: move from one search field to the next in HTML content.
- Images: move to images.

You will not hear every option on every screen. Web options appear when you are in web or HTML content. Text options appear when you are in text. That is normal.


TYPING, SPEECH, AND LIVE RECOGNITION OPTIONS
Typing Mode lets you switch among Standard Typing, Touch Typing, and Direct Touch Typing. Swipe up or down to change modes. Chapter 1.10 explains each mode. You can also set a typing style in Settings > Accessibility > VoiceOver > Typing > Typing Style.

Speech-related rotor options Apple documents include:

- Voices: switch between VoiceOver voices and languages.
- Speaking Rate: speed up or slow down speech.
- Volume: make VoiceOver louder or softer.

There is also a Live Recognition rotor option for descriptions of your surroundings and of onscreen images and interface elements, including in apps and on webpages that do not provide accessibility information. Chapter 1.21 covers this, including Apple's safety warning.


ACTIONS
On many items, VoiceOver can offer more than one action. Apple's Home Screen instructions say: tap an app, then swipe down to hear available actions, such as Edit Mode. Apple Watch documentation says to listen for "actions available," then swipe up or down and double-tap. The same pattern is used all over iPhone.

If vertical swipes are changing speaking rate or moving by heading instead of listing actions, turn the rotor to Actions first, then swipe up or down.


PRACTICE EXERCISE
1. Open Settings.
2. Turn the rotor until you hear Headings, then swipe down and up to jump from heading to heading.
3. Turn the rotor to Speaking Rate and adjust it up and down. Return it to a comfortable speed.
4. Open a webpage in Safari, set the rotor to Headings, then to Links, and move with swipes up and down.
5. Open a text field, such as in Notes or Messages, and see whether Typing Mode is on the rotor.

- Rotate two fingers, or drag one finger up and the other down, to choose a rotor setting.
- Swipe up or down to use the setting: previous or increase, next or decrease.
- The rotor list changes with context. Headings and links are especially useful on the web.
- Characters, Words, and Lines move through text.
- Typing Mode, Voices, Speaking Rate, and Volume are common non-navigation settings.
- Set the rotor to Actions when you want an item's extra actions.

Chapter 1.9. Customizing the Rotor

OVERVIEW
The rotor becomes faster when it contains only the items you actually use, in an order that makes sense to you. Some options are on the rotor by default. Others are optional. You choose them in Settings.

This chapter stays with what Apple documents for adding, removing, and reordering rotor items, adding voices, and hearing confirmation when a rotor action occurs.


WHAT YOU'LL LEARN
- Where to find the full list of rotor items.
- How to add, remove, and reorder items.
- How to add a voice you can switch to from the rotor.
- How to turn on spoken confirmation of rotor actions.
- Why some items appear only in certain contexts, even after you enable them.


CHOOSE ROTOR ITEMS
Apple's rotor article says you can see the full list of available rotor options at Settings > Accessibility > VoiceOver > Rotor > Rotor Items.

The User Guide describes a slightly shorter path: Settings > Accessibility > VoiceOver, then Rotor, where you choose the settings you want or drag to reorder them. If your iOS 26 Settings list uses a Rotor Items screen inside Rotor, follow what you hear on your phone. The destination is the same: the list of rotor options.

To choose options:

1. Go to Settings > Accessibility > VoiceOver > Rotor, and open Rotor Items if you hear that screen name.
2. Select each option you want on the rotor. Double-tap to select or deselect, following the switch or selection control VoiceOver speaks.
3. Leave options you never use turned off, so the dial has fewer stops.


REORDER ROTOR ITEMS
1. Go to the same Rotor Items list.
2. Find the Reorder button for the item you want to move. VoiceOver typically speaks this as "Reorder" followed by the item name.
3. Use the drag method Apple documents: drag the Reorder button to rearrange the item.

If dragging is awkward, you can also look for actions on the Reorder button or on the item. Swipe up or down to hear available actions, then double-tap. Use whichever method your phone offers rather than forcing a drag that you cannot feel clearly.

A practical order for many beginners is: Speaking Rate, Actions, Headings, Links, Characters, Words, Lines, Typing Mode, then everything else. There is no official required order. Put the items you use constantly next to each other so a small turn finds them.


ADD A VOICE TO THE ROTOR
You can add another VoiceOver voice and switch to it from the rotor. Apple points this to the Speech settings:

1. Go to Settings > Accessibility > VoiceOver > Speech.
2. Select Add Rotor Voice, then double-tap.
3. Choose a voice. To choose an enhanced voice, Apple says to tap Download first if the voice needs to be downloaded.
4. After the voice is added, use the Voices rotor setting to switch among voices and languages.

You can also change your primary voice in Speech settings. Chapter 1.15 covers voices, rate, and language in more detail.


HEAR CONFIRMATION OF ROTOR ACTIONS
1. Go to Settings > Accessibility > VoiceOver > Verbosity.
2. Turn on Speak Confirmation.

VoiceOver can then confirm rotor actions, which helps when you are still learning whether a swipe changed a value or moved to an item.


REMEMBER THAT CONTEXT STILL MATTERS
Some options are not always on the rotor even if you enabled them. Apple's example is Typing Mode, which is on the rotor only when there is a keyboard. Web items such as Landmarks or Visited Links appear in web or HTML content. This is expected, not a sign that your settings were lost.

For web browsing, you can also set which rotor items are used while browsing in Settings > Accessibility > VoiceOver > Rotor. Chapter 1.19 returns to this in Safari.


PRACTICE EXERCISE
1. Open Settings > Accessibility > VoiceOver > Rotor (and Rotor Items if needed).
2. Make sure Headings, Links, Actions, Speaking Rate, and Characters are enabled.
3. Move Speaking Rate and Actions near the start of the list if you use them often.
4. If you read in more than one language, add a rotor voice for the second language.
5. Turn on Speak Confirmation if you want spoken confirmation while you practice.
6. Go back to Settings or Safari and turn the rotor to confirm that your new order is what you hear.

- Choose and reorder rotor items in Settings > Accessibility > VoiceOver > Rotor (Rotor Items).
- Keep the list short enough to turn quickly.
- Add rotor voices in Settings > Accessibility > VoiceOver > Speech > Add Rotor Voice.

Chapter 1.10. Typing Options
============================================================

OVERVIEW
When VoiceOver is on, the onscreen keyboard does not work like a keyboard for sighted typing unless you choose a mode that allows that. Apple documents three typing styles, plus dictation.

The three styles are Standard Typing, Touch Typing, and Direct Touch Typing. You can change the style in Settings, or with the Typing Mode rotor setting when a keyboard is showing.

This chapter covers those styles, accented characters, and typing feedback. Braille Screen Input has its own chapter next. Handwriting and a fuller dictation lesson follow in Chapter 1.12. Text selection and editing are in Chapter 1.13.


WHAT YOU'LL LEARN
- How to open the keyboard in a text field.
- How Standard, Touch, and Direct Touch Typing each work.
- How to switch typing styles with the rotor or in Settings.
- How to enter accented characters.
- How to start and stop dictation from the keyboard.
- How to change typing feedback and phonetic feedback.


OPEN A TEXT FIELD
1. Select a text field, then double-tap.
2. The insertion point and the onscreen keyboard appear.

The insertion point is the place where the next character will be added. VoiceOver typically tells you when a text field is being edited.


STANDARD TYPING
Standard Typing is the most precise style, and it is a good default while you are learning.

1. Select a key by swiping left or right on the keyboard, or by moving your finger around the keyboard until you hear the key.
2. Double-tap to enter the character.

Or use a split-tap: keep one finger on the key, then tap the screen with another finger.

VoiceOver speaks the key when it is selected, and speaks it again when the character is entered.

To enter an accented character in Standard Typing:

1. Select the plain character, such as E.
2. Double-tap and hold until you hear a tone that indicates alternate characters have appeared.
3. Drag left or right to select and hear the choices.
4. Release your finger to enter the current selection.


TOUCH TYPING
Touch Typing is faster once you know the keyboard layout.

1. Touch a key to select it. VoiceOver speaks the character.
2. If it is the wrong key, slide your finger to the key you want.
3. Lift your finger to enter the character.

VoiceOver does not enter a character until you lift your finger. That is the main difference from Direct Touch Typing.

To enter an accented character in Touch Typing, touch and hold a character until the alternate characters appear, then move to the one you want. Follow what VoiceOver speaks as the alternates appear.


DIRECT TOUCH TYPING
In Direct Touch Typing, VoiceOver is disabled for the keyboard only. You type the same way you do when VoiceOver is off. This can be fast if you already type by feel, but you will not hear keys spoken as you explore them on the keyboard.

Direct Touch Typing does not turn VoiceOver off in the rest of iPhone. It only changes typing on the keyboard.


DICTATION FROM THE KEYBOARD
Apple documents a two-finger double tap on the keyboard to start and stop dictation. Dictation must be enabled first.

1. Go to Settings > General > Keyboard.
2. Turn on Enable Dictation, and confirm if iPhone asks.
3. Open a text field and show the keyboard.
4. Two-finger double tap on the keyboard to start dictation.
5. Speak, then two-finger double tap again to stop.

Chapter 1.12 has more dictation commands, such as punctuation and "new line," from Apple's Dictation guide.


SWITCH TYPING STYLES
In Settings:

1. Go to Settings > Accessibility > VoiceOver.
2. Select Typing Style, or open Typing and then Typing Style, depending on what your iOS 26 Settings list speaks.
3. Choose Standard Typing, Touch Typing, or Direct Touch Typing.

From the rotor:

1. When the keyboard is showing, turn the rotor to Typing Mode.
2. Swipe up or down until you hear the style you want.


TYPING FEEDBACK
Still in Settings > Accessibility > VoiceOver, Apple documents these related options:

- Phonetic Feedback: VoiceOver speaks a character, then its phonetic equivalent, such as "F" and then "foxtrot."
- Typing Feedback: choose to speak characters, words, both, or nothing.
- Verbosity, then Deleting Text: you can have VoiceOver speak deleted characters in a lower pitch by choosing Change Pitch.

These settings help you catch mistakes without slowing down more than you want. Many people speak characters and words while learning, then switch to words only.


PRACTICE EXERCISE
1. Open Notes and create a new note, or open a message to yourself.
2. Double-tap the text field to show the keyboard.
3. Type a short sentence in Standard Typing.
4. Switch to Touch Typing with the rotor and type another sentence.
5. Try a two-finger double tap to start dictation, say a short phrase, then stop dictation the same way.
6. If you try Direct Touch Typing, type only a few characters, then switch back if you need spoken keys.


QUICK REFERENCE SUMMARY
- Double-tap a text field to show the keyboard and the insertion point.
- Standard Typing: select a key, then double-tap or split-tap to enter it.
- Touch Typing: touch a key, slide to correct, lift to enter.
- Direct Touch Typing: type as if VoiceOver were off, but only on the keyboard.
- Two-finger double tap on the keyboard starts and stops dictation.
- Change styles in Settings or with the Typing Mode rotor item.
- Adjust Phonetic Feedback, Typing Feedback, and deleted-text verbosity in VoiceOver settings.

Chapter 1.11. Braille Screen Input
============================================================

OVERVIEW
Braille Screen Input lets you type braille directly on the iPhone screen with your fingers, without a physical braille keyboard. You can also use it to enter braille commands for navigating and controlling iPhone.

If you already read and write braille, this can be the fastest way to type on a phone. If you do not know braille, you can skip this chapter for now and use Standard Typing, Touch Typing, or dictation.

Apple's current iPhone User Guide notes that on iPhone 18 Pro models, you can also enter eight-dot braille by tapping with up to eight fingers at the same time. On other models, six-dot entry is the usual method described here.


WHAT YOU'LL LEARN
- How to start and exit Braille Screen Input.
- The difference between tabletop mode and screen away mode.
- The official gestures for space, delete, new line, suggestions, and more.
- How Command Mode works, at a high level.
- Which settings Apple documents for Braille Screen Input.


START BRAILLE SCREEN INPUT
With VoiceOver on, use one of these methods.

Use a gesture:

1. Place one finger from each hand at the top and bottom edges of the screen and double-tap.
2. If that gesture does not work, go to Settings > Accessibility > VoiceOver > Braille, tap Braille Screen Input, then turn on Use Activation Gestures.

Use the rotor:

1. Move to a text input area.
2. Set the rotor to Braille Screen Input.
3. If Braille Screen Input is not in the rotor, go to Settings > Accessibility > VoiceOver > Rotor, open Rotor Items, and select Braille Screen Input.

You can also have Braille Screen Input start automatically when you enter a text field. That option is in the Braille Screen Input settings listed later in this chapter.


CHOOSE A POSITION
Apple documents two positions:

- Tabletop mode: lay iPhone flat in front of you.
- Screen away mode: hold iPhone in landscape orientation with the screen facing away from you. Your fingers wrap around the sides of iPhone to tap the screen.

Enter braille characters by tapping the screen with one or more fingers at the same time.

To hear where each dot is located, touch and hold, then drag your finger around the screen.

To move the entry dots to match your natural finger positions, Apple says to tap and lift your right three fingers all at once to position dots 4, 5, and 6, followed immediately by your left three fingers for dots 1, 2, and 3.


GESTURES WHILE TYPING BRAILLE
Apple documents the following gestures. In screen away mode, a swipe right means a swipe to your right.

- Swipe right with one finger: enter a space.
- Swipe left with one finger: delete the previous character.
- Swipe right with two fingers: move to a new line.
- Swipe up or down with one finger: cycle through spelling suggestions.
- Swipe up with three fingers: enter a carriage return, or send a message in Messages.
- Swipe left or right with three fingers: cycle through modes, such as Braille Entry Mode and Command Mode.
- Swipe down with two fingers: translate immediately, if you are typing contracted braille.
- Swipe up with two fingers: switch to the next braille table.


EXIT BRAILLE SCREEN INPUT
Do one of the following:

- Slide two fingers in opposite directions.
- Or do a two-finger scrub: draw the letter "z" by quickly moving two fingers back and forth three times.


COMMAND MODE
Braille Screen Input has a Command Mode that lets you control iPhone by typing braille commands on the screen. Apple says you can use the same commands you use with a refreshable braille display.

1. Start Braille Screen Input with the activation gesture (one finger from each hand at the top and bottom edges, then double-tap).
2. Swipe left or right with three fingers to switch to Command Mode.
3. Type braille commands on the screen.

Apple points to its article "Common braille commands for VoiceOver on your iPhone, iPad, and iPod touch" for the command list. This book does not reprint that full command table. Use Apple's article, or Settings > Accessibility > VoiceOver > Commands > Braille Screen Input, where you can view and edit commands and gestures.


BRAILLE SCREEN INPUT SETTINGS
Go to Settings > Accessibility > VoiceOver > Braille > Braille Screen Input. Apple documents options including:

- Use Activation Gestures: allow the top-and-bottom-edge double-tap to start Braille Screen Input. If this is off, use the rotor.
- Start Automatically when Editing Text: start Braille Screen Input when you enter a text field.
- Keep Active until Dismissed: after you launch an app or choose an item in Braille Entry Mode, automatically switch to Command Mode and keep it active.
- Customize Commands: assign new braille keys to a command.
- Learn Dot Positions: calibrate the positions of dots as you enter them.
- Reverse Dot Positions: for six-dot braille, swap the positions of dots 1 and 3, and of dots 4 and 6.
- Visual Text Feedback: show a text translation of what you type. This is for a sighted helper or for residual vision. It is not required for entry.
- Typing Feedback: sound or haptic feedback as you type.
- Single Hand Mode Style: options for typing in portrait orientation, including Right Hand or Left Hand, Slate and Stylus, and Reversed Slate and Stylus. Apple notes that in Right Hand or Left Hand style, you type a column of dots and swipe right to enter an empty column, then double-tap to enter one braille cell. Right Hand is on by default. In Slate and Stylus, dots 1, 2, and 3 are on the right and dots 4, 5, and 6 are on the left. Reversed Slate and Stylus flips that.
- Mode Announcements: when you switch modes, have VoiceOver speak, play sounds, or both.
- Choose a Braille table: select a braille format.

Apple's page uses the wording "Reversed Slated and Stylus" in at least one listing. The meaning is reversed slate-and-stylus layout.

Single-hand mode is the way to type braille with one hand when iPhone is in portrait. If you use two hands in tabletop or screen away mode, you may never need it.


PRACTICE EXERCISE
Only do this if you already know braille, or if you are exploring with a braille teacher.

1. Enable Braille Screen Input on the rotor and turn on Use Activation Gestures.
2. Open Notes and double-tap a text field.
3. Start Braille Screen Input with the rotor or the activation gesture.
4. Practice a few characters, a space (one-finger swipe right), and a delete (one-finger swipe left).
5. Exit with a two-finger scrub or by sliding two fingers in opposite directions.


QUICK REFERENCE SUMMARY
- Start from the rotor in a text field, or by placing one finger from each hand at the top and bottom edges and double-tapping.
- Tabletop: phone flat. Screen away: landscape, screen facing away, fingers wrapped around.
- One-finger swipe right is space. One-finger swipe left is delete. Two-finger swipe right is a new line.
- Three-finger swipe left or right cycles Entry and Command modes.
- Exit by sliding two fingers in opposite directions, or with a two-finger scrub.
- iPhone 18 Pro models can enter eight-dot braille with up to eight fingers.
- Review commands in Settings > Accessibility > VoiceOver > Commands > Braille Screen Input.

- How to add handwriting to the rotor and write characters.

- How to enter a passcode silently, and how to launch an app by writing its name.

USE HANDWRITING MODE
1. Set the rotor to Handwriting.
2. If Handwriting is not in the rotor, go to Settings > Accessibility > VoiceOver > Rotor and add it.
3. To choose a character type (lowercase, numbers, uppercase, or punctuation), swipe up or down with three fingers.
4. To hear the selected character type, tap with three fingers.
5. Trace a character on the screen with your finger.

Apple also documents these handwriting gestures:

- Enter an alternate character, such as an accented letter: write the character, then swipe up or down with two fingers until you hear the character you want.
- Enter a space: swipe right with two fingers.
- Go to a new line: swipe right with three fingers.
- Delete the previous character: swipe left with two fingers.

To exit handwriting mode, do a two-finger scrub, or set the rotor to a different setting.


ENTER A PASSCODE SILENTLY
On the passcode screen:

1. Set the rotor to Handwriting.
2. Write the characters of your passcode with your finger.

This avoids having digits spoken out loud, which matters in public. Braille Screen Input is the other silent method Apple mentions when you unlock iPhone.


SELECT AN ITEM ON THE HOME SCREEN BY WRITING
1. On the Home Screen, set the rotor to Handwriting.
2. Start writing the name of the item with your finger.
3. If there are multiple matches, continue to spell the name until it is unique, or swipe up or down with two fingers to choose from the current matches.


TURN ON AND USE DICTATION
1. Go to Settings > General > Keyboard.
2. Turn on Enable Dictation. If a prompt appears, confirm Enable Dictation.
3. In a text field, place the insertion point where you want to begin. With VoiceOver, select the field and double-tap, then move the insertion point if needed (see Chapter 1.13).
4. Start dictation. With VoiceOver, Apple documents a two-finger double tap on the keyboard. You can also activate the Dictation button on the keyboard if you hear it.
5. When dictation is listening, begin speaking.
6. To stop, do a two-finger double tap on the keyboard again, activate the stop control if you hear it, say "Stop dictation," or remain silent for 30 seconds. Apple says dictation stops automatically after 30 seconds of silence.

Apple notes that dictation may not be available in all languages or in all countries or regions, and that features may vary. When you dictate in a search field, dictated text may be sent to the search engine to process the search. In many languages, dictation is processed on iPhone and does not require an internet connection, but you should still read Apple's "About Dictation & Privacy" information in Keyboard settings if you want the official privacy details.


SPOKEN DICTATION COMMANDS
Apple's Dictation guide documents commands such as the following:

- Add emoji by saying the name, such as "heart emoji" or "smiley face emoji."
- Add punctuation by saying the name, such as "exclamation point."
- In supported languages, Dictation can insert commas, periods, and question marks automatically. To turn that off, go to Settings > General > Keyboard and turn off Auto-Punctuation.
- Say "new line" or "new paragraph" to add a line break.
- Spell a word, for example: "Let's invite Steven S-T-E-P-H-E-N."
- Correct spelling, for example: "Change tea to T-E-E."
- Edit text by saying "select" or "delete" followed by the phrase you want to change.
- Say "undo" or "redo."

You can mix dictation and typing. Type a correction, then start dictation again.

5. Optional: on the Lock Screen, practice handwriting for a passcode only if no one else can hear or see the practice, and only if you are willing to enter your real passcode or a test device passcode.

- Write a character with one finger. Two-finger swipe right is space. Two-finger swipe left deletes. Three-finger swipe right is a new line.
- Handwriting can enter a passcode silently and can find Home Screen items by name.

- Say punctuation, "new line," spelling, and "undo" as needed. Availability varies by language and region.

============================================================

Chapter 1.13. Text Editing
============================================================

OVERVIEW
Typing is only half of working with text. You also need to move the insertion point, select text, and cut, copy, paste, or fix a typo. VoiceOver does this with the rotor and a few gestures, not with a visible mouse pointer.

This chapter follows Apple's "Use the onscreen keyboard with VoiceOver" page. Practice in Notes, where a mistake does not send a message.


WHAT YOU'LL LEARN
- How to move the insertion point by character, word, or line.
- How VoiceOver reports that movement.
- How to select text with Text Selection or Edit.
- How to cut, copy, paste, fix misspellings, and undo.


MOVE THE INSERTION POINT
1. Double-tap a text field so you are editing it.
2. Set the rotor to Characters, Words, or Lines, depending on how far you want to move.
3. Swipe up or down to move the insertion point backward or forward.
4. To jump to the beginning or end, Apple says to double-tap the text.

VoiceOver makes a sound when the insertion point moves, and it speaks the character, word, or line that the insertion point moves across.

When you move forward by words, the insertion point is placed at the end of each word, after the space or punctuation that follows. When you move backward, the insertion point is placed before the first character of the word.

If you need to move past the punctuation at the end of a word or sentence, switch the rotor back to Characters.

When you move by line, VoiceOver speaks each line as you move across it. When moving forward, the insertion point is placed at the end of the next line. When moving backward, the insertion point is placed at the beginning of the line that is spoken.


DELETE A CHARACTER
Select the Delete key on the onscreen keyboard, then enter it using your current typing style (for example, double-tap in Standard Typing). Apple's User Guide shows a Delete control here. This book does not invent a special delete gesture for the standard keyboard. Braille Screen Input and handwriting have their own delete gestures, taught in those chapters.


SELECT TEXT
Apple documents two methods.

Method A: Text Selection rotor item.

1. If Text Selection is not on the rotor, go to Settings > Accessibility > VoiceOver > Rotor and enable it.
2. Set the rotor to Text Selection.
3. Swipe up or down to choose Character, Word, Line, or Sentence.
4. Swipe left or right to move backward or forward, extending or moving the selection as VoiceOver describes it.

Method B: Edit rotor item.

1. Set the rotor to Edit.
2. Swipe up or down to choose Select or Select All, then double-tap.
3. If you choose Select, the word closest to the insertion point is selected when you double-tap.
4. To increase or decrease the selection, do a two-finger scrub to dismiss the pop-up menu, then pinch.

Pinch means move two fingers together or apart on the screen. Listen to VoiceOver as the selection changes, and stop when you hear the range you want. If pinching is difficult, use the Text Selection rotor method instead.


CUT, COPY, OR PASTE
1. Select the text.
2. Set the rotor to Edit.

4. Double-tap to use the replacement.

1. Shake iPhone.
2. Swipe left or right to choose the action to undo.
3. Double-tap.

Apple's "Operate iPhone when VoiceOver is on" page documents search from the Home Screen and two ways to rearrange apps. It does not give a separate VoiceOver-only name for the App Library. In current iOS, the App Library is the screen you reach by moving past the last Home Screen page, and it can also be opened from the Dock on some layouts. - How to explore Home Screen pages and the Dock.
- How to search from the Home Screen.
- How to rearrange apps by dragging, or by using Move actions.

EXPLORE THE HOME SCREEN
1. Go to the Home Screen using the method for your iPhone model (Chapter 1.7).
2. Drag your finger to hear app names, or swipe right and left to move in order.
3. The Dock is the row of apps that stays on every Home Screen page. With the rotor set to Containers, you can often jump between the Home Screen and the Dock, because Apple lists both as examples of containers.
4. To move between Home Screen pages, use a three-finger swipe left or right.

A four-finger tap near the top selects the first item. A four-finger tap near the bottom selects the last item. These help on a crowded page.


SEARCH FROM THE HOME SCREEN
Apple documents this method:

1. Tap anywhere on the Home Screen outside the status bar.
2. Swipe down with three fingers.

Then use the search field: double-tap to begin editing, type or dictate, and swipe through the results. Double-tap a result to open it.

This is one of the fastest ways to open an app you cannot remember the location of.


THE APP LIBRARY
After the last Home Screen page, iOS provides the App Library, which groups apps into categories and offers its own search field. With VoiceOver:

1. From a Home Screen page, three-finger swipe left to scroll toward later pages (that swipe scrolls the pages to the right).
2. Continue until you hear App Library, or a search field and app categories instead of your usual page of icons.
3. Explore by touch or by swiping. Use the search field the same way you would any other text field.

If you keep apps only in the App Library and not on a Home Screen page, Search is often faster than browsing categories. This book does not invent additional App Library-only VoiceOver gestures beyond ordinary exploration, scrolling, and search.


REARRANGE APPS BY DRAGGING
1. Tap the icon you want to move.
2. Double-tap and hold your finger on the screen until you hear three rising tones.
3. Drag. VoiceOver describes the item's relative location as you move.
4. Lift your finger when the icon is in its new location.
5. Drag an icon to the edge of the screen to move it to another Home Screen page.


REARRANGE APPS WITH MOVE ACTIONS
1. Tap an app.
2. Swipe down to hear available actions. If swipes are not listing actions, set the rotor to Actions first.
3. When you hear "Edit Mode," double-tap to start arranging apps.
4. Find the app you want to move, swipe down to the Move action, and double-tap.
5. Move the VoiceOver cursor to the new destination.
6. Choose from the available actions Apple lists: Cancel Move, Create New Folder, Add to Folder, Move Before, or Move After.
7. When you are finished, select Done, then double-tap.

This method is often easier than dragging if you want precise placement, such as "Move Before Messages."


PRACTICE EXERCISE
1. Swipe through one Home Screen page, then three-finger swipe to another page.
2. Open Search from the Home Screen with a three-finger swipe down, and search for Settings.
3. Move one app using Edit Mode and the Move action, then move it back or leave it if you prefer the new place.
4. Scroll until you reach the App Library and explore its search field.

- Drag: double-tap and hold until three rising tones, then drag. VoiceOver describes the location.

You can change how VoiceOver sounds: the voice, the language, the speaking rate, the pitch, and how VoiceOver shares the speaker with music or calls. Most of these settings are in Settings > Accessibility > VoiceOver, and in the Speech and Audio screens there.

This chapter follows Apple's "Change your VoiceOver settings on iPhone" page. Volume of the iPhone itself, including VoiceOver, is also controlled by the volume buttons.

VOLUME AND AUDIO
To increase or decrease iPhone volume, including VoiceOver speech and sounds and other iPhone audio, press the volume buttons on iPhone.

If VoiceOver is speaking too softly relative to music, a call, or a video, try audio ducking:

1. Go to Settings > Accessibility > VoiceOver > Audio.
2. Select Audio Ducking, then choose When Speaking.
3. Drag the Ducking Amount slider to set how much the volume decreases for other iPhone audio, such as media and calls, while VoiceOver is speaking.

Other Audio options Apple documents include:

- Sounds & Haptics: adjust and preview sound effects and haptics.
- Auto-select Speaker in Call: automatically switch to the speaker during a call when you are not holding iPhone to your ear.
- Send to HDMI: route audio to externally connected devices, such as an instrument amplifier or a DJ mixer.

You can also change VoiceOver volume from the rotor when Volume is one of your rotor items (Chapter 1.8).


SET THE LANGUAGE
VoiceOver uses the same language you choose for iPhone.

1. To choose a different primary language, go to Settings > General > Language & Region, then select Add Language and follow the onscreen steps.

You can switch languages using the rotor by switching to a voice for another language.

VoiceOver can also detect text in another language and automatically switch to a voice for that language:

1. Go to Settings > Accessibility > VoiceOver > Speech.
2. Turn on Detect Languages.

Apple notes that VoiceOver is not available in all languages, and points to the Apple Support article "Languages supported by VoiceOver."


CHANGE THE SPEAKING VOICE
1. Go to Settings > Accessibility > VoiceOver > Speech.
2. To change the primary voice, select the name of the current primary voice, then select Voice.
3. To add another voice for the rotor, select Add Rotor Voice.
4. Choose a voice. To choose an enhanced voice, Apple says to download it first if needed.

Enhanced voices usually sound clearer but take storage space and may need to download on Wi-Fi. If a voice is still "downloading," wait before judging its quality.


ADJUST RATE, PITCH, AND PRONUNCIATIONS
Go to Settings > Accessibility > VoiceOver, then:

- Adjust the speaking rate by using the Speaking Rate slider. You can also change rate from the rotor at any time, which is often easier.
- Adjust the pitch: open Speech, select a voice, then use the pitch slider.
- Turn on Pitch Change if you want VoiceOver to use a higher pitch when speaking the first item of a group (such as a list or table) and a lower pitch when speaking the last item of a group.
- Specify how certain words are pronounced: go to Speech > Pronunciations, add a new entry, enter a phrase, then dictate or spell out how you want it pronounced. Apple notes that you can dictate only if Enable Dictation is on in Settings > General > Keyboard (Apple's page may say Keyboards).


PRACTICE EXERCISE
1. Press the volume buttons and set a comfortable VoiceOver volume in a quiet room.
2. Open Speech settings, listen to your current voice, and try one alternative if you want a change.
3. Adjust Speaking Rate with the slider, then again with the rotor, and pick a speed you can follow for a whole Settings screen.
4. If you regularly read another language, add a rotor voice and turn on Detect Languages.
5. Optional: add a pronunciation for a name VoiceOver always misreads.

- Speaking Rate is both a slider and a rotor item.
- Pitch Change uses a higher pitch at the start of a group and a lower pitch at the end.
- Pronunciations live under Speech. Dictation for pronunciations needs Enable Dictation.

Chapter 1.16. Verbosity, Punctuation, Activities, and Navigation Style
============================================================

OVERVIEW
Verbosity is how much VoiceOver tells you. You can change punctuation reading, notification reading, hints, and many other details. Activities let you save a group of VoiceOver settings and apply them automatically in certain apps or contexts. Navigation Style chooses between Flat and Grouped movement.

These settings are how VoiceOver goes from "talkative beginner" to "quiet and efficient," without turning off information you still need.


WHAT YOU'LL LEARN
- Where to find Verbosity and what Apple documents there.
- How punctuation groups work.
- How Activities can switch settings for you.
- The difference between Flat and Grouped navigation, including the two-finger swipe gestures for groups.
- How Delay before Selection can reduce accidental touches.


SET HOW MUCH VOICEOVER TELLS YOU
1. Go to Settings > Accessibility > VoiceOver > Verbosity.
2. Review the options, and change only what you understand. You can come back later.

Apple documents the following in particular:

- Punctuation: select Punctuation, then choose a group. You can also create new groups. Apple's example is a programming group in which "[" is spoken as "left bracket."
- System Notifications: by default, VoiceOver reads notifications, including incoming text messages, as they occur, even if iPhone is locked. Unacknowledged notifications are repeated when you unlock iPhone. You can change this behavior here.
- Additional options: VoiceOver can speak hints, uppercase letters, embedded links, and more. It can confirm rotor actions and tell you when the flashlight is turned on.

A practical starting point is to leave hints on while you learn, keep punctuation at a medium or some-punctuation group so you hear question marks and emails clearly, and turn on Speak Confirmation if the rotor still surprises you. Then reduce verbosity once the extra words feel like noise.


CREATE OR EDIT AN ACTIVITY
An activity is a bundle of VoiceOver settings for a situation, such as programming. When you open certain apps, or when you choose the activity from the rotor, VoiceOver can apply settings for speech, audio, verbosity, typing, navigation, and braille automatically.

1. Go to Settings > Accessibility > VoiceOver > Activities.
2. Choose an existing activity, or select Add Activity.
3. Adjust the settings for that activity.
4. Under Automatic Switching, do either or both of the following:
   - Apps: select the apps this activity should use.
   - Context: select one or more contexts, such as Word Processing, Messaging, or Console.

Use activities when you want, for example, more punctuation and a different voice in a coding app, and quieter speech in Messages. If you do not need this yet, skip it. A simpler setup is easier to troubleshoot.


CHOOSE FLAT OR GROUPED NAVIGATION
1. Go to Settings > Accessibility > VoiceOver > Navigation Style.
2. Choose Flat or Grouped.

Flat: VoiceOver moves sequentially through each item on the screen when you use next and previous, such as swipe right and swipe left.

Grouped: VoiceOver moves through items and groups of items. To move into a group, use a two-finger swipe right. To move out of a group, use a two-finger swipe left.

If next-item swipes seem to skip controls inside a toolbar or a list, you may be in Grouped style and need to move into the group. If movement feels too long and you hear every small element, Flat may already be what you want.


REDUCE ACCIDENTAL SELECTION
You can control the time between touching the screen and VoiceOver selecting the item you touched. Increasing this delay may help reduce accidental touches.

1. Go to Settings > Accessibility > VoiceOver > Delay before Selection.
2. Increase or decrease the delay using the controls VoiceOver speaks.

This is useful if exploring by touch keeps selecting items you only meant to slide across.


OTHER VISUAL OPTIONS, BRIEFLY
Apple also documents Large Cursor and Caption Panel in VoiceOver settings. Large Cursor enlarges and thickens the outline around the selected item, which can help people with some residual vision. Caption Panel shows the text VoiceOver is speaking at the bottom of the screen, which can help a sighted teacher or a deafblind user who also uses braille or remaining vision. Neither is required to use VoiceOver by ear.


PRACTICE EXERCISE
1. Open Verbosity and listen through the list once without changing anything.
2. Check your Punctuation group, and try a different group in a Notes sentence that includes commas and a question mark. Keep the one you prefer.
3. Confirm Navigation Style. If it is Grouped, practice two-finger swipe right and left on the Home Screen. If it is Flat, try Grouped once so you can recognize it later.
4. Optional: create one activity for an app where you want different verbosity, and assign that app under Automatic Switching.


QUICK REFERENCE SUMMARY
- Verbosity is at Settings > Accessibility > VoiceOver > Verbosity.
- Punctuation groups can be chosen or created, including special groups for programming.
- VoiceOver can read notifications even on the Lock Screen. Change this under System Notifications if you need it quieter.
- Activities store a set of VoiceOver settings and can switch by app or context.
- Flat navigation visits every item in order. Grouped navigation uses two-finger swipe right to enter a group and two-finger swipe left to leave it.
- Delay before Selection can reduce accidental touches.

MAKE AND RECEIVE PHONE CALLS

2. Double-tap a message to open it.
3. Use a two-finger swipe down to read the message from the current point, or move by lines and paragraphs with the rotor.
4. For messages in HTML, rotor items such as Headings, Links, and Landmarks can work the same way they do in Safari.
5. To reply or compose, activate the relevant button, double-tap each address or subject field you need to edit, and write in the body field.

MOVE BY PAGE ELEMENT

2. Swipe down to move to the next one, or swipe up to move to the previous one.

Useful web rotor items, when they appear, include Headings, Links, Visited Links, Non-visited Links, In-Page Links, Landmarks, Buttons, Form Controls, Text Fields, Search Fields, Tables, Lists, Images, and Static Text. Chapter 1.8 defines these.

A good habit on a new page:

1. Two-finger swipe up to hear the top of the page, then pause.
2. Set the rotor to Headings and swipe down through the outline.
3. When you find the section you want, swipe right to read the content, or set the rotor to Lines or Static Text.
4. Use Links when you are ready to follow something.

Landmarks help on sites that mark banners, navigation, and main regions in HTML. Not every site provides them. If Landmarks does nothing useful, use Headings.


SET ROTOR ITEMS FOR WEB BROWSING
1. Go to Settings > Accessibility > VoiceOver > Rotor.
2. Select or deselect items, or drag to reposition an item.

Keep Headings, Links, Landmarks, Form Controls, and perhaps Images if you use those often. A shorter web rotor is faster to turn than a rotor that includes every optional item.


SKIP IMAGES
1. Go to Settings > Accessibility > VoiceOver > Navigate Images.
2. Choose to skip all images, or only those without descriptions.

Skipping images without descriptions can make a page faster if it is full of unlabeled graphics. If you need every image, do not skip them, and consider Screen Recognition or image descriptions from Chapter 1.22.


USE READER VIEW
Reader View reduces page clutter for easier reading and navigation. It is not available for all webpages.

1. In the Safari address field, select the Format Options button, then double-tap.
2. Select Show Reader View, then double-tap.

If you do not hear Format Options or Show Reader View, the page may not support Reader View, or the control may be named slightly differently in your iOS version. Explore the address field and nearby buttons rather than inventing a gesture.

Once Reader View is on, Headings and reading gestures are often much cleaner.


KEYBOARD TIP
If you use a Magic Keyboard with iPhone, Apple says you can use single-key Quick Nav for web browsing. Chapter 1.23 lists the Quick Nav commands this book could confirm from Apple's keyboard page, such as H for heading and L for link.


PRACTICE EXERCISE
1. Open Safari and search for a familiar, well-structured site, such as an Apple Support article or a news site you trust.
2. Move by Headings through the page, then read one section with a two-finger swipe down.
3. Switch the rotor to Links and move among a few links without activating them.
4. Look for Format Options and try Reader View. If it is not available, try a different article.
5. Optional: change Navigate Images and notice whether the page is faster to move through.


QUICK REFERENCE SUMMARY

- Choose those rotor items in Settings > Accessibility > VoiceOver > Rotor.

Chapter 1.21. Live Recognition, Magnifier, and Detection Mode
============================================================

OVERVIEW
VoiceOver Recognition can describe what is on the screen and, with Live Recognition, what the rear camera sees around you. The Magnifier app also offers Detection Mode for live descriptions of visual information. These tools can be genuinely useful. They can also be wrong.

Apple's warning is important enough to repeat in Apple's own sense, if not Apple's exact legal wording: VoiceOver Recognition should not be relied upon in circumstances where you could be harmed or injured, in high-risk situations, for navigation, or for the diagnosis or treatment of any medical condition.

Use these features as helpful extra information, not as a sole source of truth about traffic, medication, or unfamiliar surroundings.


WHAT YOU'LL LEARN
- How to start and stop Live Recognition.
- What you can ask it to describe, and which detections need supported iPhone models.
- Where to customize Live Recognition settings, including a shortcut and the Action button.
- How Magnifier's Detection Mode fits alongside Live Recognition.
- The limits you should treat as hard limits.


START AND STOP LIVE RECOGNITION
With VoiceOver on, triple-tap the screen with four fingers to start Live Recognition. Use the same four-finger triple tap to turn it off.

If the VoiceOver cursor is focused on an interface element for Live Recognition, you can also do a two-finger scrub to turn it off.

Apple says you can set up a shortcut to start and stop Live Recognition quickly, and that you can customize the Action button on supported models so you can quickly access VoiceOver, the Magnifier app, or asking a question in Live Recognition. See Apple's "Set up shortcuts for Live Recognition" page for the shortcut details, because those steps can vary by model.


USE LIVE RECOGNITION
After you start Live Recognition:

1. Position iPhone so the rear camera can detect what is around you. VoiceOver describes what the camera detects.
2. To interrupt VoiceOver speech and move to the next detected item, tap the screen with two fingers.
3. Double-tap when you hear Ask to turn asking questions on or off. Apple says the default question "What is this?" is asked automatically unless you customize Live Recognition settings.
4. Choose the kinds of visual information you want described, such as scenes, people, doors, furniture, or text. Select a category, then double-tap to turn it on or off.
5. If you turn on Point and Speak, you can point your finger at text and have VoiceOver read it aloud.
6. Double-tap when you hear Document Capture to turn that on or off if you need information about a document.

Apple notes that detection of people, doors, and furniture is available only on supported iPhone models. If you do not hear those categories, your model may not include them.


CUSTOMIZE LIVE RECOGNITION SETTINGS
1. Go to Settings > Accessibility > Live Recognition. Note that this path is under Accessibility, not nested only inside VoiceOver.
2. Apple documents options such as:
   - Default Question, which is "What is this?" by default. You can also enter your own default question.
   - Speak or Type as the default way to ask.
   - Use Volume Buttons to Recapture, if you want the volume buttons to take a picture.
   - Live Recognition Rotor: choose what appears, such as People, Doors, Scenes, or Ask, and drag to reorder.
   - Activities: create a custom activity with a name, choose which detection modes are on by default, and optionally turn on Speech, Braille, Sounds, and Haptics for different detection modes.

Again, people, doors, and furniture detection depends on supported models.


MAGNIFIER AND DETECTION MODE
Apple's Live Recognition page also says you can use Detection Mode in the Magnifier app to detect and describe scenes, people, and more, and it points to the Magnifier topic "Get live descriptions of visual information around you with Magnifier."

This book does not invent Magnifier button names or Detection Mode gestures beyond that official pointer. If you use Magnifier:

1. Open the Magnifier app, or add Magnifier to Control Center or the Action button if you use it often.
2. Explore the controls with VoiceOver and look for Detection Mode or similar live-description options.
3. Follow the labels on your iOS 26 device, and Apple's Magnifier User Guide, for the exact steps.

Magnifier remains useful even without Detection Mode, as a camera-based magnifier for people with some residual vision, and as another place to work with the camera when VoiceOver is on.


PRACTICE EXERCISE
Practice in a familiar, safe indoor space, not near a street or a stove.

1. Start Live Recognition with a four-finger triple tap.
2. Point the rear camera at a known object, such as a closed book on a table, and listen to the description.
3. Turn a category on or off, then stop Live Recognition with another four-finger triple tap.
4. Open Settings > Accessibility > Live Recognition and listen through the settings once.
5. Optional: open Magnifier and find whether Detection Mode is available on your phone.


QUICK REFERENCE SUMMARY

- Use the rear camera. A two-finger tap skips to the next detected item.
- Ask, scenes, people, doors, furniture, text, Point and Speak, and Document Capture are official categories or tools. People, doors, and furniture need supported models.
- Customize in Settings > Accessibility > Live Recognition.
- You can also use Detection Mode in Magnifier. Confirm the controls on your device.
- Do not rely on these features for safety, navigation, or medical decisions.

CHOOSE THE VOICEOVER MODIFIER
The modifier is the key or keys you press with one or more other keys to enter VoiceOver commands. You can set it to Caps Lock, or to Control and Option pressed together.

1. Go to Settings > Accessibility > VoiceOver > Typing > Modifier Keys.
2. Choose Caps Lock, or Control and Option.

This book writes the modifier as VO. "VO-Space bar" means hold your chosen modifier and press the Space bar.


KEYBOARD HELP
VoiceOver Help, also called Keyboard Help, speaks keys and keyboard commands as you type them, without performing the action.

- VO-K turns VoiceOver Help on.
- Escape turns VoiceOver Help off.

Use this when you are learning a new shortcut.


CORE COMMANDS
Apple documents these VoiceOver keyboard commands (VO is the modifier):

- VO-K: turn on VoiceOver Help.
- Escape: turn off VoiceOver Help.
- VO-Right Arrow or VO-Left Arrow: select the next or previous item.
- VO-Space bar: activate the selected item.
- VO-Shift-M: touch and hold the selected item.
- VO-A: read from the current position.
- VO-B: read from the top.
- Control: pause or resume reading.
- VO-Shift-C: copy the last spoken text to the clipboard.
- VO-F: search for text.
- VO-S: mute or unmute VoiceOver.
- VO-H: go to the Home Screen.
- VO-M: move to the status bar.
- From the status bar, Option-Up Arrow: open the notifications screen.
- From the status bar, Option-Down Arrow: open Control Center.
- Option-Up Arrow: open Search. (This is also how Apple lists Search as a command of its own.)
- VO-H-H: open the App Switcher.
- VO-I: open the Item Chooser.
- VO-Slash: change the label of the selected item.
- VO-Hyphen: start, stop, or pause an action (Magic Tap's keyboard equivalent).
- VO-Up Arrow or VO-Down Arrow: swipe up or down (use with the rotor).
- VO-Command-Left Arrow or VO-Command-Right Arrow: turn the rotor left or right.
- VO-Command-Up Arrow or VO-Command-Down Arrow: adjust the setting specified by the rotor.
- VO-Fn-Hyphen, or VO-Globe-Hyphen, depending on your keyboard: turn Screen Curtain on or off.

Apple's iPhone keyboard page also has a "Return to the previous screen" row. The shortcut itself was not clearly shown in the version retrieved for this book, so it is omitted here rather than guessed. Escape is used for that purpose on some other Apple platforms, but you should confirm the iPhone behavior in VoiceOver Help or in Apple's current table.


QUICK NAV WITH ARROW KEYS
Quick Nav lets you control VoiceOver with the arrow keys.

- Left Arrow-Right Arrow, pressed together, turns Quick Nav on or off.
- Right Arrow or Left Arrow: select the next or previous item.
- Up Arrow or Down Arrow: select the next or previous item specified by the rotor.
- Control-Up Arrow or Control-Down Arrow: select the first or last item.
- Up Arrow-Down Arrow, pressed together: tap (activate) an item.
- Option-Up Arrow, Option-Down Arrow, Option-Left Arrow, or Option-Right Arrow: scroll up, down, left, or right.

Apple's table also includes an "Adjust the rotor" Quick Nav row whose exact key combination was not clearly retrieved. Use VO-Command-Arrow keys from the main command list, or check the official table on your device.


SINGLE-KEY QUICK NAV FOR WEB BROWSING
To navigate a webpage quickly, Apple says to turn on Quick Nav (VO-Q), then press keys to move to specific item types. Hold Shift with a key to move to the previous item of that type.

- H: Heading
- L: Link
- R: Text field
- B: Button
- C: Form control
- T: Table
- S: Static text
- W: ARIA landmark
- M: Item of the same type
- 1 through 6: Level 1 heading through level 6 heading

Apple's table also contained additional letters whose labels were not clearly retrieved. This book does not invent those letters. TEXT EDITING ON A KEYBOARD
Apple lists text commands that work with Quick Nav turned off. VoiceOver reads text as you move the insertion point. Clearly retrieved commands include:

- Right Arrow or Left Arrow: go forward or back one character.
- Up Arrow or Down Arrow: go up or down one line.
- Command-Left Arrow or Command-Right Arrow: go to the beginning or end of the line.
- Shift plus any of the insertion point movement commands: select text as you move.

Some mid-row commands, such as moving by word, were not fully retrieved from the official table and are therefore omitted here. Option-Left Arrow and Option-Right Arrow are the usual Mac and iPadOS pattern for moving by word, but confirm with VoiceOver Help on iPhone before you rely on an unlisted shortcut.

2. Press VO-K and press a few command combinations. Hear what they do, then press Escape.
3. Use VO-Right Arrow and VO-Space bar to move and activate on the Home Screen.
4. Press VO-H for Home, VO-S to mute and unmute, and VO-I for the Item Chooser.
5. In Safari, turn on Quick Nav with VO-Q if needed, and use H and L to move by heading and link.

With VoiceOver, you can connect a Bluetooth refreshable braille display and use it to control iPhone and read what is on the screen. - How 2D braille displays can use a rotor mode, if you have one.

CONNECT A BRAILLE DISPLAY
1. Turn on the braille display.
2. On iPhone, go to Settings > Bluetooth, turn on Bluetooth, then choose the display.
3. Go to Settings > Accessibility > VoiceOver > Braille, then choose the display.
4. To see the braille commands for controlling iPhone, select More Info, then select Braille Commands.

Apple publishes "Braille displays supported by iPhone, iPad, and iPod touch" and "Common braille commands for VoiceOver on your iPhone, iPad, and iPod touch." Start there if a display will not pair, or if you need the command chords.

You can also turn on Enable Bluetooth on Start in VoiceOver Braille settings, so Bluetooth turns on automatically when you turn on VoiceOver and displays can connect.


CHANGE BRAILLE SETTINGS
Go to Settings > Accessibility > VoiceOver > Braille. Apple documents options including:

- Match Input and Output Tables: use the same table for typing and for reading.
- Input and Output: choose tables for input and output, including additional languages, six-dot or eight-dot, and contracted or uncontracted braille.
- Braille Screen Input: the onscreen braille method from Chapter 1.11.
- Braille Tables: add tables to the braille table rotors.
- Braille Access: quickly access braille notes, BRF files, and more using a braille display. Apple points to a separate "Change Braille Access settings" page for details.
- Item Overview: adjust the number of cells displayed per item. Press dots 6, 7, and 8 at the same time to turn Item Overview on or off.
- Automatic Translation: translate the braille you type into text soon after you stop typing.
- Status Cells: turn on general and text status cells and choose their location.
- Equations use Nemeth Code: use Nemeth Code for mathematical equations.
- Show Onscreen Keyboard: display the keyboard on the screen.
- Turn Pages when Panning: automatically turn pages when panning.
- Word Wrap: wrap words to the next line.
- Text Formatting: display attributes such as bold and italics.
- Use Underline Cursor: display the cursor as an underline.
- Braille Alert Messages: when on, the display shows an alert for a specified duration.
- Ignore Chord Duration: how long before later key presses are recognized as braille chords.
- Auto Advance Duration: adjust this to your preferred reading speed.
- Sound Curtain: when a braille display is connected, mute most sounds. Emergency alerts still play sounds.
- Enable Bluetooth on Start: described above.

You do not need to change all of these. Many people set input and output tables, word wrap, and auto advance, then leave the rest until a specific need appears.


CAPTIONS IN BRAILLE
To output closed captions in braille during media playback:

1. Go to Settings > Accessibility > VoiceOver > Verbosity.
2. Choose Braille, or Speech and Braille, in the media or captions-related option Apple provides there.

The User Guide's VoiceOver-in-apps page also notes that equations spoken by VoiceOver can be output to a braille device using Nemeth Code, as well as codes used by Unified English Braille, British English, French, and Greek.


USE A 2D BRAILLE DISPLAY
If you use a supported 2D braille display, you can use the rotor to switch between output modes, such as a mode for displaying images or a mode for reading text on multiple lines.

1. Connect the display to iPhone.
2. With VoiceOver on, use the Braille Text Mode rotor to switch between output modes.

See Chapter 1.8 for rotor use. If you do not have a 2D display, you can ignore this section.


PRACTICE EXERCISE
1. If you have a display, pair it in Bluetooth, then select it in Settings > Accessibility > VoiceOver > Braille.
2. Open More Info > Braille Commands and listen to, or read in braille, a few commands you already use.
3. Confirm your input and output tables.
4. Open a Notes document and practice reading and typing a sentence.
5. If you use captions, set Verbosity so captions can go to the display during a short video.


QUICK REFERENCE SUMMARY
- Pair in Settings > Bluetooth, then choose the display in Settings > Accessibility > VoiceOver > Braille.
- Braille Commands are under More Info for that display.
- Set input and output tables, translation, word wrap, and auto advance to match how you read.
- Sound Curtain can mute most sounds while a display is connected. Emergency alerts still sound.
- Enable Bluetooth on Start can connect a display whenever VoiceOver turns on.
- 2D displays can use the Braille Text Mode rotor.
- Official supported-display and common-command lists are on Apple's Support site. This book does not replace them.

============================================================
VOICEOVER MASTERY: THE COMPLETE APPLE GUIDE
A book in SRTS: Screen Reader Training Suite
Part 1. iPhone (iOS)
Chapter 1.25. Troubleshooting Common VoiceOver Problems on iPhone
============================================================

OVERVIEW
Most "VoiceOver is broken" moments are not a broken iPhone. Speech may be muted. Screen Curtain may be on. Zoom may have changed a gesture. The speaking rate may be extremely fast or slow. This chapter is a checklist, starting with the fastest checks.

If you cannot use the screen at all, use the Accessibility Shortcut, Siri, or a restart. Set the shortcut up before you need it (Chapter 1.1).


WHAT YOU'LL LEARN
- What to try when speech stops, the screen seems dead, or gestures do nothing.
- How Zoom changes mute and Screen Curtain gestures.
- How to recover if VoiceOver is on and you did not want it, or off and you cannot see the screen.
- When to reset VoiceOver commands or settings.
- How to restart iPhone.


SPEECH STOPPED
Work through these in order:

1. Try a three-finger double tap to unmute VoiceOver. If Zoom is also on, use a three-finger triple tap instead.
2. Press the volume buttons to raise iPhone volume. VoiceOver uses that volume.
3. Check whether you are wearing headphones, hearing aids, or another Bluetooth audio device that is connected but not being heard. Disconnect or change the audio output if needed.
4. Do a two-finger tap. If VoiceOver was paused, this continues speaking.
5. Turn the rotor to Volume or Speaking Rate and swipe up. You may have set the rate or volume extremely low.
6. If a braille display is connected, Sound Curtain may have muted most sounds. Emergency alerts should still play. Check Braille settings, or turn the display off to test.
7. Ask Siri, "Turn VoiceOver off," then "Turn on VoiceOver," if you can use Siri.


THE SCREEN SEEMS BLACK OR THE PHONE SEEMS OFF
If iPhone still makes VoiceOver sounds, plays haptics, or responds to gestures, Screen Curtain is the first suspect.

1. Use a three-finger triple tap to toggle Screen Curtain. If Zoom is also on, use a three-finger quadruple tap.
2. If you use a Bluetooth keyboard, Apple documents Control-Option-Shift-S (that is, VO-Shift-S on some keyboards) in its Screen Curtain article for iPhone, iPad, and iPod touch. The iPhone User Guide's keyboard table also lists VO-Fn-Hyphen or VO-Globe-Hyphen. Try the command that matches your keyboard, or use the touch gesture above.

Remember: when Screen Curtain is on, iPhone is active and VoiceOver still works, even though the display is off.


GESTURES DO NOTHING OR DO THE WRONG THING
1. Try a quicker double tap or swipe, with space between fingers for multifinger gestures. Practice in VoiceOver Practice if you can open it.
2. Make sure you are not in the middle of a passthrough gesture (double-tap and hold until three tones). Lift your fingers and try again.
3. If Zoom is on, remember that mute and Screen Curtain need extra taps, and some gestures may conflict. Try turning Zoom off with the Accessibility Shortcut if Zoom is on that shortcut.
4. If you customized commands, a default gesture may have been reassigned. Go to Settings > Accessibility > VoiceOver > Commands > Touch Gestures, or use Reset VoiceOver Commands.
5. If navigation skips items, check Navigation Style (Flat versus Grouped) and whether you need to move into a group with a two-finger swipe right.
6. If you are in Braille Screen Input, handwriting, or another input mode, exit it (two-finger scrub is the usual escape) and try again.


VOICEOVER IS ON AND YOU WANT IT OFF
Use any of these:

- Triple-click the side button or Home button if the Accessibility Shortcut includes VoiceOver.
- Ask Siri to turn VoiceOver off.
- Use Control Center if VoiceOver is there.
- Go to Settings > Accessibility > VoiceOver and double-tap the VoiceOver switch. If you are new to the gestures, remember: swipe to the switch, then double-tap.

If someone turned VoiceOver on by accident and you can see the screen, the same methods work. The double tap instead of a single tap is the usual surprise.


VOICEOVER IS OFF AND YOU NEED IT ON
- Triple-click the side button or Home button if the shortcut is set.
- Ask Siri to turn VoiceOver on.
- Use Control Center if VoiceOver is there.
- Go to Settings > Accessibility > VoiceOver and turn it on with a standard tap, because VoiceOver is off.
- During device setup, Apple documents using the Accessibility Shortcut as well. On iPad, a triple-click of the top button or Home button during setup turns VoiceOver on. iPhone setup follows the same idea. If you are already past setup, use the methods above.


SPEECH IS THE WRONG LANGUAGE OR VOICE
1. Check Settings > General > Language & Region.
2. Check Settings > Accessibility > VoiceOver > Speech, including Detect Languages and rotor voices.
3. Make sure the rotor is not sitting on a second language voice by accident.


RESET SETTINGS OR COMMANDS
If behavior is still wrong after the checks above:

1. Reset VoiceOver Commands in Settings > Accessibility > VoiceOver > Commands, if gestures feel remapped.
2. Reset VoiceOver Settings in Settings > Accessibility > VoiceOver (you may need to scroll down), if a setting change is the likely cause. You will have to restore voice, rate, and rotor preferences afterward.


RESTART IPHONE
A restart clears many temporary glitches. Apple's standard method for current iPhones with Face ID is:

1. Press and quickly release the volume up button.
2. Press and quickly release the volume down button.
3. Press and hold the side button.
4. When the power or restart slider appears, slide to power off, or keep holding until iPhone restarts, depending on the official steps shown on your model.
5. If the device powers off, press and hold the side button to turn it back on.

On iPhone SE, Apple's usual method is to hold the side button and a volume button, then use the power slider, or follow the iPhone SE restart article for your generation.

If VoiceOver is on, use volume and side buttons, which do not require seeing the screen. If a slider appears, use a standard VoiceOver drag: select the slider, double-tap and hold until three rising tones, then drag, or use the Actions available on the slider.

If iPhone is frozen and does not respond, Apple documents a force restart: press volume up quickly, volume down quickly, then hold the side button until the Apple logo appears (Face ID models). Do not invent other button combinations.


GET MORE HELP
If none of this works, contact Apple Support, visit an Apple Store, or ask a trusted person to help you check Settings while you keep control of the device. This book is not a repair manual.

Wisconsin readers and others in the United States can also use vocational rehabilitation or a local blindness organization for VoiceOver training, which is often more helpful than troubleshooting hardware alone.


PRACTICE EXERCISE
Do this while VoiceOver is working, so the recovery gestures are in muscle memory.

1. Mute speech with a three-finger double tap, then unmute it.
2. Turn Screen Curtain on, confirm that speech still works, then turn Screen Curtain off. Use the Zoom-adjusted versions if Zoom is on.
3. Confirm that your Accessibility Shortcut toggles VoiceOver, then turn VoiceOver back on.
4. Find Reset VoiceOver Commands and Reset VoiceOver Settings, but do not use them unless you need to.


QUICK REFERENCE SUMMARY
- Speech stopped: three-finger double tap (triple tap if Zoom is on), then volume, headphones, two-finger tap, rate/volume rotor, braille Sound Curtain, Siri.
- Black screen but VoiceOver still works: three-finger triple tap for Screen Curtain (quadruple tap if Zoom is on).
- Gestures wrong: speed and finger spacing, exit input modes, check Zoom, check custom commands, check Flat/Grouped navigation.
- Use the Accessibility Shortcut and Siri to turn VoiceOver on or off when you are stuck.
- Reset commands or reset VoiceOver settings only after the quick checks fail.
- Restart with the hardware buttons if iPhone is still unresponsive.

Chapter 2.2. Unlock, Home, Dock, and System Gestures on iPad
============================================================

OVERVIEW
iPad uses special VoiceOver gestures to unlock, go Home, show the Dock, switch apps, open Control Center, and view notifications. They are close to iPhone's gestures, but not identical, and they vary by iPad model.

This chapter follows Apple's "Operate iPad when VoiceOver is on" page. Learn the methods that match your hardware.


WHAT YOU'LL LEARN
- How to unlock each kind of iPad Apple documents.
- How to go Home and how to show the Dock.
- How to switch apps and use the App Switcher.
- How to open and dismiss Control Center and notifications.
- How to search the Home Screen and rearrange apps.


UNLOCK IPAD
On an iPad with a Home button: press the Home button using the finger you registered with Touch ID.

On an iPad with Touch ID in the top button: rest your finger on the top button using the finger you registered with Touch ID.

On an iPad with Face ID: wake iPad and glance at it, then drag up from the bottom edge of the screen until you hear two rising tones (if Face ID is enabled).

If you are prompted for a passcode, enter it. To avoid having the passcode spoken, use handwriting mode or onscreen braille, just as on iPhone.


GO TO THE HOME SCREEN
- Drag one finger up from the bottom edge of the screen until you hear two rising tones, then lift your finger.
- On an iPad with a Home button, you can also press the Home button.


USE THE DOCK
Slide one finger up from the bottom edge until you hear two rising tones, then swipe down.

The Dock holds frequently used apps and, on many iPads, a control that leads to the App Library. After you show the Dock, swipe through its icons and double-tap to open one. This Dock gesture is one of the clearest iPad-only VoiceOver techniques. Practice it until the two tones, then the downward swipe, feel automatic.


SWITCH APPS
Swipe right or left with four fingers to cycle through open apps. This is the same idea as on iPhone.

Alternatively, use the App Switcher:

1. Drag one finger up from the bottom edge until you hear three tones, then lift your finger. Or, on an iPad with a Home button, double-click the Home button.
2. Swipe left or right until the app you want is selected.
3. Double-tap to open it.

Going Home is two rising tones and lift. Opening the App Switcher is three tones and lift. Move slowly enough to hear the difference.


OPEN CONTROL CENTER
- Drag one finger down from the top edge of the screen until you hear two rising tones.
- Or tap any item in the status bar, then swipe up with three fingers.

Dismiss Control Center with a two-finger scrub.


VIEW NOTIFICATIONS
- Drag one finger down from the top edge of the screen until you hear three rising tones.
- Or tap any item in the status bar, then swipe down with three fingers.

Dismiss notifications with a two-finger scrub.

On iPad, Apple's User Guide describes these top-edge gestures in tones (two versus three), rather than the vibration-or-tone wording used for iPhone in the iOS 26 guide. Listen for two tones for Control Center and three for notifications.


STATUS BAR, SEARCH, AND REARRANGING APPS
These match iPhone closely.

To hear status bar information, tap the status bar at the top, then swipe left or right to hear the time, battery state, Wi-Fi, and more.

To search from the Home Screen, tap anywhere on the Home Screen outside the status bar, then swipe down with three fingers.

To rearrange apps, Apple documents the same two methods as on iPhone:

- Drag and drop: select an icon, double-tap and hold until three rising tones, drag as VoiceOver describes the location, and lift. Drag to the edge to move to another page.
- Move actions: select an app, swipe down to hear actions, double-tap Edit Mode, find the app, choose Move, then use Cancel Move, Create New Folder, Add to Folder, Move Before, or Move After. Select Done, then double-tap when you finish.


PRACTICE EXERCISE
1. Go Home with the method for your iPad.
2. Show the Dock: slide up from the bottom until two rising tones, then swipe down. Open an app from the Dock, then go Home again.
3. Open the App Switcher (three tones, then lift, or double-click Home), and switch apps.
4. Open Control Center (two tones from the top), dismiss it with a scrub, then open notifications (three tones from the top) and dismiss those too.


QUICK REFERENCE SUMMARY
- Unlock: Home button with Touch ID, top button with Touch ID, or Face ID plus a drag up from the bottom until two rising tones.
- Home: drag up from the bottom until two rising tones, then lift, or press Home.
- Dock: drag up until two rising tones, then swipe down.
- App Switcher: drag up until three tones, then lift, or double-click Home. Four-finger swipes also cycle apps.
- Control Center: from the top, two rising tones, or status bar plus three-finger swipe up.
- Notifications: from the top, three rising tones, or status bar plus three-finger swipe down.
- Search, status bar, and rearranging apps work like iPhone.

CHOOSE HOW APPS APPEAR

   - Windowed Apps: resize and arrange app windows to work in more than one app at a time.
   - Stage Manager: group app windows for tasks or projects, with other open apps in a list on the left side of the screen.

Related options Apple documents in that Settings screen include whether windows close when you swipe Home, whether recent apps hide in Stage Manager, whether a double-tap at the top of a window zooms it (off by default), whether the Dock hides automatically, whether the menu bar hides automatically, and whether Picture in Picture starts automatically. Those options appear depending on the mode you chose.

If you are new to VoiceOver on iPad, Full Screen Apps is the simplest place to start. Add windowed modes after Home, Dock, and App Switcher are comfortable.


USE DOCUMENTED VOICEOVER METHODS TO MOVE BETWEEN APPS
These remain official in the VoiceOver operate-iPad page, regardless of multitasking mode:

- Four-finger swipe left or right cycles open apps.
- The App Switcher: drag up from the bottom until three tones, then lift, or double-click Home, then swipe among apps and double-tap.
- The Dock: slide up from the bottom until two rising tones, then swipe down, and open another app from there.
- Command-Tab on an external keyboard switches apps.

After you open a second app, explore the screen with VoiceOver. You may hear a divider, extra windows, a recent-apps list, or a menu bar, depending on the mode. Use next and previous, the Item Chooser (two-finger triple tap), and Containers on the rotor to map the new layout. Activate only controls you have identified.


WHAT THIS BOOK DOES NOT INVENT
It does not invent VoiceOver-specific gestures for:

- Dragging a window to Split View.
- Grabbing a resize handle.
- Moving an app to the left or right column, except where Apple documents that kind of action on a specific product.
- Stage Manager's recent-apps list beyond "explore it if you hear it."

If Apple documents additional VoiceOver window actions on your iPadOS version, they will usually appear as Actions on a window, a title bar, or a divider. Select the item, set the rotor to Actions, and swipe up or down. Follow the action names you hear.

The iPhone User Guide's unversioned pages also described Split View actions on a product called iPhone Duo. That material was not in the iOS 26 "Operate iPhone" page, and it is not treated here as iPad documentation. Do not assume iPhone foldable actions apply to iPad.


PICTURE IN PICTURE
Apple documents that when Start PiP Automatically is on, videos and FaceTime calls can continue in Picture in Picture when you go Home or open another app. If a small video window remains, select it and check Actions for controls such as closing or expanding it. Use the names iPad speaks, not guessed button titles.


PRACTICE EXERCISE
1. Open Settings > Multitasking & Gestures and note which mode is currently on.
2. If you are learning, try Full Screen Apps first. Open two apps and move between them with a four-finger swipe and with the App Switcher.
3. Show the Dock and open a second app from it.
4. If you already use Stage Manager or Windowed Apps, open two apps you know well, explore with the Item Chooser, and listen for Actions on a window or divider. Do not change modes in the middle of important work.


QUICK REFERENCE SUMMARY

OVERVIEW
VoiceOver on Mac is the same idea as on iPhone, but the main tools are a keyboard and an app called VoiceOver Utility. You move a VoiceOver cursor, hear the item in that cursor, and use a VoiceOver command to act on it.

A VoiceOver command is a combination of keys. You press the VoiceOver modifier plus one or more other keys. This book writes the modifier as VO. By default, VO is either Caps Lock, or Control and Option pressed together.

This part is based on Apple's VoiceOver User Guide for Mac, as published when this SRTS: Screen Reader Training Suite edition was written in November 2026. WHAT YOU'LL LEARN
- How to turn VoiceOver on or off.
- What the welcome dialog can do the first time.
- How VO commands are written and entered.
- How to move the VoiceOver cursor and activate an item.


TURN VOICEOVER ON OR OFF
Apple documents all of these methods:

- Press Command-F5.
- If your Mac or Magic Keyboard has Touch ID, press and hold the Command key, then quickly press Touch ID three times.
- Ask Siri something like, "Turn on VoiceOver."
- Choose Apple menu > System Settings, then click Accessibility in the sidebar (you may need to scroll down). Click VoiceOver, then turn VoiceOver on or off. With VoiceOver already on, you would use VoiceOver commands to follow that path.
- Use the Accessibility Shortcuts panel: press Option-Command-F5, or quickly press Touch ID three times if your Mac or Magic Keyboard has Touch ID. In the panel, press Tab until you hear the VoiceOver option, then press the Space bar.
- You can also add a Control Center shortcut for VoiceOver, according to Apple's getting-started page.

Command-F5 is the one to memorize first. On some keyboards you may need Command-Fn-F5 if function keys are set to system features. If Command-F5 does nothing, try it with Fn, or use the Touch ID method, Siri, or the Accessibility Shortcuts panel.


THE WELCOME DIALOG
When you turn VoiceOver on, a welcome message is spoken and a dialog is shown. Apple documents these keys in that dialog:

- Return: turn on VoiceOver.
- Space bar: turn on VoiceOver and start the interactive VoiceOver tutorial.
- V: turn on VoiceOver and prevent the dialog from appearing the next time.
- Escape: turn off VoiceOver and exit the dialog.

To control whether the dialog appears, go to VoiceOver Utility (VO-Fn-F8 when VoiceOver is on), open the General category, and select or deselect "Display welcome dialog when VoiceOver starts."


MOVE AND ACTIVATE
The VoiceOver cursor is the item VoiceOver is on. It appears onscreen as a rectangular outline, which can help a sighted helper, but you do not need to see it.

- Press VO-Left Arrow or VO-Right Arrow to move the VoiceOver cursor.
- Press VO-Space bar to perform the default action for the item, such as clicking a button or selecting a checkbox.

As you navigate, you may hear a hollow sound effect that means there are no more items in that direction.

This is the Mac equivalent of swipe left or right, then double-tap, on iPhone.


PRACTICE EXERCISE
1. Turn VoiceOver on with Command-F5, or with Command and three presses of Touch ID.
2. If the welcome dialog appears, press Space bar if you want the tutorial now, or Return to continue with this book.
3. Press VO-Right Arrow a few times and listen, then VO-Space bar on a safe item such as a folder or button you know.
4. Turn VoiceOver off and on once more, so the toggle is comfortable.
5. Leave VoiceOver on for the next chapter.

- Option-Command-F5 opens the Accessibility Shortcuts panel.

- The welcome dialog: Return to continue, Space bar for the tutorial, V to skip the dialog next time, Escape to cancel.
- Open VoiceOver Utility with VO-Fn-F8.

THE VOICEOVER MODIFIER
By default, you can press Control and Option together, or just press Caps Lock, as the VoiceOver modifier. Apple also documents a command to lock and unlock the modifier: VO-Semicolon. When the modifier is locked, you can enter VO commands without holding VO down each time. Unlock it with the same command when you are done, so ordinary typing is not affected, especially if you use Caps Lock as VO.

If you type in all caps accidentally after practicing, check whether Caps Lock is on, and check whether the VO modifier is locked.


FUNCTION KEYS
Apple's general commands page includes this important note: by default, when you use a function key (F1 through F12) in a VoiceOver command, you must also press the Fn key. Depending on your Mac, you can change that behavior so you do not have to press Fn.

You can also enter VoiceOver commands that use a function key by using Fn and a number key instead of Fn and a function key. Apple's example: to open VoiceOver Utility, you can press VO-Fn-8 instead of VO-Fn-F8.

If a command in this book includes F7, F8, or another function key and nothing happens, try it with Fn, or try the number-key variant.


KEYBOARD HELP
Keyboard Help lets you press a key and hear its name, or press a VoiceOver combination and hear what it does, without typing text or performing the command.

- Press VO-K to start or stop Keyboard Help.

This is the Mac version of VoiceOver Practice. Use it whenever this book introduces a new command.


HELP, TUTORIAL, AND THE USER GUIDE
Apple documents these official help commands:

- VO-H: open the VoiceOver Help menu.
- VO-H-H: open the Commands menu.
- VO-Shift-F: open the Find Commands menu, according to the general commands list.
- VO-Fn-Command-F8: open the VoiceOver Tutorial.
- VO-Question Mark: open the VoiceOver User Guide.
- VO-Shift-H: read the help tag for the current item. Apple's general commands page also mentions descriptions of maps in Apple Maps in connection with this command.
- VO-Shift-N: read the VoiceOver hint for the current item.

The tutorial is worth doing once, even if you already use VoiceOver on iPhone. Mac interaction with groups, the rotor, and window choosers is easier after the official lesson.


OTHER USEFUL GENERAL COMMANDS
From Apple's general commands list, these are worth knowing early:

- VO-Fn-F8: open VoiceOver Utility.
- VO-N: open the Notifications menu.
- VO-Fn-F7: read the current date and time.
- VO-Fn-F7-F7: read the battery status of your Mac.
- VO-Fn-F7-F7-F7: read the network status of your Mac.
- Escape or Fn-Tab: close a menu or rotor, stop an action, or exit a mode.
- VO-Tab: tell VoiceOver to ignore the next key or key combination you press.
- VO-S: mute or unmute VoiceOver, listed on related pages. For a complete mute of the VoiceOver voice or of sound effects without turning VoiceOver off, Apple also documents VoiceOver Utility > Speech or Sound settings.

============================================================

OVERVIEW
Content in VoiceOver on Mac is organized hierarchically. Some items contain other items. Apple calls an item that contains nested items an area (such as a list of files) or a group (such as a toolbar of buttons).

By default, you must interact with an area or group before you can navigate to its items. That lets you skip a group, or stop and go inside it. This is the biggest conceptual difference from iPhone's usual swipe-through-everything habit, especially if your iPhone navigation style is Flat.


WHAT YOU'LL LEARN
- How to move the VoiceOver cursor and activate items, reviewed briefly.
- How to start and stop interacting with an area or group.
- How to recognize when interaction is required.
- How this compares to grouped navigation on iPhone.


MOVE AND ACTIVATE, AGAIN
- VO-Left Arrow or VO-Right Arrow moves the VoiceOver cursor.
- VO-Space bar performs the default action.

If nothing else is in that direction, VoiceOver can play a hollow sound. Change direction or interact with the current item if it is a group.


INTERACT WITH A GROUP
When the VoiceOver cursor moves to an area or group, VoiceOver indicates that you are on an item that can be interacted with.

- Press VO-Shift-Down Arrow to interact with the area or group.
- Press VO-Shift-Up Arrow to stop interacting and exit the area or group.

After you interact, you can navigate only within that area or group until you exit it. This is similar to moving into a group on iPhone with a two-finger swipe right, then out with a two-finger swipe left, if you use grouped navigation.

If you press VO-Right Arrow and seem to skip a whole toolbar or list, you probably need to interact first. If you get "stuck" inside a table or sidebar, press VO-Shift-Up Arrow to exit, then move on.


TRACKPAD EQUIVALENTS
If you use trackpad gestures (Chapter 3.6):

- Two-finger flick right starts interacting with the item in the VoiceOver cursor.
- Two-finger flick left stops interacting.

Those official trackpad gestures match the keyboard interact and exit commands.


PRACTICE EXERCISE
1. Open Finder, or a folder on the desktop.
2. Move with VO-Right Arrow until VoiceOver says you can interact with a list, toolbar, or group.
3. Press VO-Shift-Down Arrow, move among the items inside, then press VO-Shift-Up Arrow to exit.
4. Repeat in Safari or System Settings, which are full of groups.
5. If you get lost, press Escape or VO-Shift-Up Arrow until you are out of the current group, then VO-H if you have already learned the Help menu, or just keep exiting until you hear a familiar window.


QUICK REFERENCE SUMMARY
- VO-arrows move. VO-Space bar activates.
- Areas and groups must often be entered before you can move to the items inside.
- VO-Shift-Down Arrow interacts (goes in). VO-Shift-Up Arrow exits.
- After you interact, movement stays inside that group until you exit.
- On a trackpad, two-finger flick right goes in, and two-finger flick left goes out.
- This is the Mac cousin of grouped navigation on iPhone.

OPEN VOICEOVER UTILITY
Do one of the following:

- When VoiceOver is on, press VO-Fn-F8. Remember that VO-Fn-8 may also work.
- Choose Apple menu > System Settings, click Accessibility in the sidebar, click VoiceOver, then click Open VoiceOver Utility.


SEARCH FOR AN OPTION

1. Interact with the toolbar in the VoiceOver Utility window (use VO-Shift-Down Arrow if needed).
2. Type what you are looking for in the search field.

EXAMPLES OF WHAT YOU CAN CHANGE

1. Open VoiceOver Utility.
2. To mute the VoiceOver voice, click the Speech category, click Voices, then select "Mute speech."
3. To turn off VoiceOver sound effects, click the Sound category, then select "Mute sound effects."

You can also control whether the welcome dialog appears, in the General category (Chapter 3.1).

For trackpad use, Command settings in VoiceOver Utility include options such as disabling the trackpad while VoiceOver is on, and "Scroll gesture moves content instead of scroll bar." Those are mentioned in Apple's trackpad pages. Change them only if you understand the result.


USE THE HELP BUTTON

PRACTICE EXERCISE

Chapter 3.6. Trackpad Gestures and the Trackpad Rotor
============================================================

OVERVIEW
If your Mac has a built-in trackpad, or if an external trackpad is connected, you can control VoiceOver with gestures. Many of them will feel familiar if you already use VoiceOver on iPhone or iPad. For example, you can tap the trackpad to hear the item in the VoiceOver cursor.

Apple often calls this the option to control VoiceOver with trackpad gestures. People also call it the Trackpad Commander. This chapter uses Apple's wording and lists only official standard gestures. Those standard gestures cannot be customized, but you can assign VoiceOver commands to additional gestures in VoiceOver Utility.


WHAT YOU'LL LEARN
- How to turn trackpad VoiceOver gestures on or off.
- The official general, navigation, interaction, text, and rotor gestures.
- How the gestures rotor works, including on webpages.
- An important note about the trackpad mouse button.


TURN TRACKPAD GESTURES ON OR OFF
To use these gestures, VoiceOver must already be on, and you must have a built-in or connected trackpad.

- To turn the option on, press and hold the VoiceOver modifier (Control-Option, or Caps Lock) and rotate two fingers clockwise anywhere on the trackpad.
- To turn it off, hold VO and rotate two fingers counterclockwise.

Apple notes that when you use VoiceOver gestures, you cannot use the mouse button on the trackpad, unless the mouse button is used with a modifier key, as in a Control-click.

If a gesture does not mention a specific number of fingers, use one finger.


GENERAL GESTURES
- VO plus a two-finger rotate clockwise: turn trackpad VoiceOver control on.
- VO plus a two-finger rotate counterclockwise: turn it off.
- Three-finger triple-tap: turn the screen curtain on or off.
- Three-finger double-tap: mute or unmute VoiceOver.


NAVIGATION GESTURES
- Hold Shift and drag a finger horizontally or vertically: force the VoiceOver cursor into a horizontal or vertical line as you drag.
- Flick right: move to the next item.
- Flick left: move to the previous item.
- Three-finger flick in any direction: move content or the scroll bar, depending on the "Scroll gesture moves content instead of scroll bar" option in VoiceOver Commands settings.
- Two-finger double-tap near the bottom of the trackpad: go to the Dock.
- Two-finger double-tap near the top of the trackpad: go to the menu bar.
- Two-finger double-tap on the left side: open the Application Chooser.
- Two-finger double-tap on the right side: open the Window Chooser, to access open windows and system dialogs.
- Press Control while touching a finger on the trackpad: jump to another area of the current app.


INTERACTION GESTURES
- Touch, including a tap or a drag: speak the item in the VoiceOver cursor, or play a sound effect if the area is blank.
- Double-tap anywhere, or split-tap (touch with one finger, then tap with a second finger): select or activate an item, in the way Apple describes as selecting the item.
- Two-finger flick right: start interacting with the item in the VoiceOver cursor.
- Two-finger flick left: stop interacting.
- Three-finger flick up or down: scroll one page down or up.
- Two-finger scrub back and forth: Escape, which closes a menu without making a selection.
- Flick up or flick down: increase or decrease the value of a slider, splitter, stepper, or other control.


TEXT GESTURES
- Two-finger flick up: read the current page starting at the top.
- Two-finger flick down: read from the VoiceOver cursor to the end of the current page.
- Three-finger tap: read the current scroll page.
- Two-finger tap: pause or resume speaking.
- Triple-tap: describe what is in the VoiceOver cursor. Apple's trackpad-gestures intro also says a three-times tap tells you your location and what is in the VoiceOver cursor.
- Press Command while dragging a finger in a text field, or while interacting with a text element, until VoiceOver reads with the granularity you want (word, line, sentence, or paragraph).


THE GESTURES ROTOR
The gestures rotor is like a virtual dial. You turn it to change how you navigate, based on context.

1. Rotate two fingers anywhere on the trackpad until you hear the setting you want, such as Words. VoiceOver speaks each setting and plays a clicking sound. If you miss a setting, keep turning until it comes around again.
2. Flick up or down to move to the previous or next instance of that item.

On webpages, the rotor settings depend on what you selected in the Web Rotor tab of the Web category in VoiceOver Utility. By default, Apple says they include Links, Headings, Form Controls, Tables, Landmarks, and Frames.

In other contexts, the rotor can include settings such as Characters, Words, Window Spots, Content Chooser, and Navigation.

Your web navigation mode affects how the gestures rotor moves on webpages. In DOM mode, flicking up or down moves to the previous or next instance of the current rotor item, such as the next heading. Apple says you can assign the "Toggle Web Navigation DOM or Group" command to a trackpad gesture if you want an easy way to switch modes. See Chapter 3.8 for more on web navigation.


OTHER TRACKPAD NOTES
You can practice trackpad gestures in Keyboard Help (VO-K). VoiceOver tells you what the gesture does without performing it.

You can set an option to disable the trackpad when VoiceOver is on, which can prevent accidental gestures. See VoiceOver Utility Commands settings.

You can customize additional, non-standard gestures by assigning VoiceOver commands to them. Do not expect to change the standard set listed in this chapter.


PRACTICE EXERCISE
1. With VoiceOver on, hold VO and rotate two fingers clockwise to enable trackpad gestures.
2. Open Keyboard Help with VO-K and try a flick right, a two-finger flick up, and a two-finger rotation. Exit Help.
3. Flick right and left to move, double-tap to activate a safe item, and use a two-finger flick right and left to interact and exit.
4. On a webpage, turn the gestures rotor to Headings and flick down through headings.
5. If you do not want the trackpad active, hold VO and rotate two fingers counterclockwise to turn this option off.


QUICK REFERENCE SUMMARY
- Hold VO and rotate two fingers clockwise to turn trackpad VoiceOver control on; counterclockwise turns it off.
- Flick left or right to move. Double-tap or split-tap to select. Two-finger flick right interacts; two-finger flick left exits.
- Two-finger flick up or down reads. Two-finger tap pauses. Three-finger double-tap mutes. Three-finger triple-tap is Screen Curtain.
- Two-finger double-tap at the bottom is the Dock; at the top is the menu bar; on the left is the Application Chooser; on the right is the Window Chooser.
- Two-finger rotate turns the gestures rotor. Flick up or down to use it.
- Standard gestures cannot be remapped. Extra gestures can be assigned in VoiceOver Utility.

When Mac VoiceOver seems to fail, start with the same ideas as on iPhone: speech may be muted, the screen curtain may be on, or you may be stuck inside a group. Then use Mac-specific toggles: Command-F5, the Accessibility Shortcuts panel, and VoiceOver Utility.

SPEECH STOPPED OR YOU HEAR NOTHING
1. Press Control to make sure speech is not only paused. Press Control again to resume.
2. If you use trackpad gestures, try a three-finger double-tap to unmute. The keyboard equivalent from Apple's general list includes VoiceOver mute in related command sets; VO-S is documented as mute on iPhone and Apple TV keyboards, and is commonly used on Mac as well. Confirm with Keyboard Help if needed, or open VoiceOver Utility > Speech > Voices and see whether "Mute speech" is selected.
3. Check the Mac volume, and check whether sound is going to headphones or another output.
4. In VoiceOver Utility, check the Sound category for "Mute sound effects" if you still need the voice but are missing clicks and earcons.
5. If a braille display is connected, speech may have been minimized on purpose. Check the Braille category and try disconnecting the display as a test.


THE SCREEN SEEMS BLANK
1. Turn the screen curtain off with VO-Shift-Fn-F11. Include the Fn key if function keys are media keys.
2. If trackpad gestures are on, a three-finger triple-tap also toggles the screen curtain.
3. If the VoiceOver cursor and caption or braille panels were hidden, Apple documents VO-Fn-Command-F11 to hide or show the VoiceOver cursor and the caption or braille panels, and other F9, F10, and F11 combinations for those panels. Try VO-Shift-Fn-F11 first, because screen curtain is the usual "blank screen" cause.


STUCK OR GESTURES AND KEYS DO NOTHING
1. Press Escape, or Fn-Tab, to close a menu, rotor, or mode.
2. Press VO-Shift-Up Arrow one or more times to exit a group.
3. If the VO modifier is locked (VO-Semicolon), unlock it, especially if Caps Lock is your modifier and typing is behaving oddly.
4. If trackpad gestures are on and the trackpad seems "dead" as a mouse, that is expected unless you use a modifier-click. Turn trackpad VoiceOver control off with VO plus a two-finger rotate counterclockwise if you need the ordinary trackpad back.
5. If commands do nothing, try adding the Fn key, or use the number-key form of function-key commands.
6. Open the Commands menu (VO-H-H) and confirm that a command still has the shortcut you expect.


TURN VOICEOVER OFF OR ON WHEN YOU ARE STUCK
- Command-F5, or Command plus three presses of Touch ID.
- Option-Command-F5, or three presses of Touch ID, then Tab to VoiceOver and press the Space bar.
- Ask Siri to turn VoiceOver on or off.
- If you can use System Settings, go to Accessibility > VoiceOver.

If someone turned VoiceOver on by accident, Command-F5 is the fastest off switch to tell them about, along with the welcome dialog's Escape key if that dialog is still up.


PRACTICE EXERCISE
1. Pause speech with Control, then resume it.
2. Turn the screen curtain on with VO-Shift-Fn-F11, confirm that VoiceOver still speaks, then turn it off.
3. Interact with a group, then practice exiting with VO-Shift-Up Arrow and with Escape.
4. Confirm that Command-F5 still toggles VoiceOver, then turn it back on.

- Triple-tap with two fingers again to turn off Digital Crown Navigation.

There is a VoiceOver settings switch named Navigate with the Digital Crown on the VoiceOver settings screen as well. If the triple-tap method and the settings switch seem to overlap on your watchOS version, follow the labels on your watch and iPhone rather than forcing both.


HAND GESTURES
You can use hand gestures instead of taps to control VoiceOver.

1. On iPhone, open the Apple Watch app, then go to My Watch > Accessibility > VoiceOver > Hand Gestures.
2. Turn on Hand Gestures.
3. Use the gestures Apple lists, including clench, double clench, tap, and double tap.

Important official note: the universal double tap gesture is not available when you turn on Hand Gestures for VoiceOver. If you rely on the watch's Double Tap (index finger and thumb) for other watch features, turning on VoiceOver Hand Gestures can take that over. Decide which you need before enabling this.

You can also configure Hand Gestures from VoiceOver settings on the watch itself.


PRACTICE EXERCISE
1. On the watch face or in Settings, explore by touch, swipe to an item, and double-tap a safe control.
2. Practice a two-finger scrub to go back.
3. Turn the rotor to Speaking Rate, change it slightly, then put it back.
4. Try Digital Crown Navigation: two-finger triple-tap, turn the crown, then two-finger triple-tap to turn it off.
5. Leave Hand Gestures off until you have read the limitation above and decided you want them.


QUICK REFERENCE SUMMARY
- Explore, swipe, and double-tap work like a small iPhone. Two-finger scrub goes back. Two-finger tap pauses speech.
- Listen for "actions available," then swipe up or down and double-tap.
- Two-finger double-tap and hold, then slide, changes VoiceOver volume.
- Rotor items Apple lists: Words, Characters, Actions, Headings, Volume, and Speaking Rate.
- Two-finger triple-tap turns Digital Crown Navigation on or off, then you turn the crown to select.
- Hand Gestures are optional and disable the universal Double Tap feature while they are on.

6. If Hand Gestures are on and the watch's usual Double Tap no longer works, that is the official limitation. Turn Hand Gestures off if you need Double Tap back.
7. Use the iPhone Apple Watch app when the watch itself is hard to control.

Chapter 5.2. Navigation Mode, Exploration Mode, and the Rotor on Apple TV
============================================================

OVERVIEW
VoiceOver on Apple TV has two modes. Navigation mode speaks selected items as you move with the remote. Exploration mode holds the currently selected item so you can browse other items and text on the screen before you choose something else.

The rotor, opened on the clickpad or touch surface, lets you adjust VoiceOver controls such as speech rate. Available rotor controls vary depending on what you are doing.

This chapter is one of the most important Apple TV lessons in this book. If the remote seems to "do the wrong thing," you may be in the other mode, or the rotor may be open.


WHAT YOU'LL LEARN
- How to switch between navigation and exploration modes.
- How each mode behaves.
- How to open, use, and exit the rotor.
- Official exploration-mode reading gestures.


SWITCH MODES
To switch between navigation and exploration modes, use two fingers to tap three times on the clickpad center or touch surface of your remote.

Remember that gesture. It is easy to do by accident if you rest two fingers on the remote, and it is the first thing to try if behavior suddenly changes.


NAVIGATION MODE
In navigation mode, as you drag your finger over the clickpad or touch surface, VoiceOver speaks each menu or text item you highlight.

1. Move to another item by navigating up, down, left, or right.
2. Press the clickpad center or touch surface to select the item.
3. Press and hold if a pop-up menu is available.

Apple also documents a Navigation Style setting that applies only in navigation mode: Follow Focus moves by one item when you swipe, and Direct Touch lets you swipe to scroll several items at a time. That setting is in Settings > Accessibility > VoiceOver, covered in the next chapter.


EXPLORATION MODE
By default, items selected in exploration mode remain selected while you browse adjacent or other items. This lets you hear what else is on the screen without immediately moving the selection.

As you drag your finger, VoiceOver highlights and speaks each menu or text item you browse. Then you can:

- Swipe left or right to hear the name of an item. The item also appears highlighted on the screen.
- Press the clickpad center or touch surface to select a highlighted item. The newly selected item remains selected until you browse and select another item.
- Swipe up or down to adjust the currently selected VoiceOver rotor control, once the rotor is in use.
- Swipe down with two fingers to speak all items starting from the current text item to the bottom of the screen. Tap the clickpad center or touch surface when you hear the item you want to stop on.
- Swipe up with two fingers to speak the items on screen, starting at the top. Tap the clickpad or touch surface to stop on an item.
- Tap once with two fingers to pause speaking, and tap again with two fingers to resume.

Apple notes that VoiceOver keyboard commands on Apple TV function, by default, as if you are in exploration mode. See the next chapter.


USE THE ROTOR
1. Rotate two fingers around a point on the clickpad center or touch surface to open the VoiceOver rotor.
2. When the rotor opens, VoiceOver speaks the currently selected control if you are in exploration mode. In navigation mode, you hear a sound before VoiceOver speaks the currently selected control.
3. Rotate two fingers left or right again to switch to another control.
4. Swipe up or down to adjust the control. VoiceOver speaks the current value. For example, rotate to the speech rate control, then swipe up or down to change the rate.
5. To exit the rotor, swipe left or right, or wait approximately three seconds. In navigation mode, an exit sound plays when the rotor closes.

If you cannot change the speech rate, the rotor may be on a different control, or it may have closed after three seconds. Open it again and listen for the control name before you swipe up or down.


PRACTICE EXERCISE
1. From the Apple TV Home Screen, move among a few apps in the current mode.
2. Two-finger triple-tap the clickpad or touch surface to switch modes, and notice what changes when you swipe.
3. In exploration mode, try a two-finger swipe up to hear items from the top, then tap to stop.
4. Open the rotor with a two-finger rotation, find speech rate, adjust it slightly, then exit the rotor by waiting or by swiping left or right.
5. Switch back to the mode you prefer for everyday use. Many people stay in navigation mode for menus and use exploration mode when a screen is crowded.


QUICK REFERENCE SUMMARY
- Two-finger triple-tap on the clickpad or touch surface switches navigation and exploration modes.
- Navigation mode: move, then press to select. Optional press-and-hold for a pop-up.
- Exploration mode: the current selection can stay put while you browse. Two-finger swipe up reads from the top. Two-finger swipe down reads from the current item. Two-finger tap pauses.
- Rotate two fingers to open the rotor, rotate to a control, swipe up or down to adjust, then swipe left or right or wait about three seconds to exit.
- If the remote behavior changes suddenly, check the mode and whether the rotor is still open.

VOICEOVER SETTINGS

AUDIO DESCRIPTIONS
Audio descriptions narrate important onscreen action in movies and TV shows when the feature is available in that content.

To turn them on, Apple documents:

- In Settings, go to Accessibility, then select Audio Descriptions.
- During video playback, show playback controls, swipe up on the clickpad or touch surface, select the relevant control, then select an Audio Descriptions (AD) option if one is available.

BLUETOOTH KEYBOARD COMMANDS
After you connect a Bluetooth keyboard, enter VoiceOver commands by holding Control and Option (VO) and pressing one or more other keys. Apple notes that, by default, these commands function as if you are in exploration mode.

Confirmed commands from Apple's Apple TV keyboard page:

- VO-K: VoiceOver Help on. Escape: Help off.
- VO-E: switch between exploration and navigation mode.
- VO-Shift-F3: turn VoiceOver and native focus syncing on or off in exploration mode.
- VO-Right Arrow or VO-Left Arrow: next or previous item.
- VO-Space bar: activate the selected item (Apple describes this as a double-tap to activate).
- VO-H: press the TV button.
- VO-Shift-M: touch and hold the selected item.
- VO-M: move to the status bar.
- VO-A: read from the current position.
- VO-B: read from the top.
- Control: pause or resume reading.
- VO-Shift-C: copy the last spoken text.
- VO-F: search for text.
- VO-S: mute or unmute VoiceOver.
- Fn-VO-Up Arrow: open the notifications screen.
- Fn-VO-Down Arrow: open Control Center.
- VO-I: Item Chooser.
- VO-Slash: change the label of the selected item.
- VO-Hyphen: double-tap with two fingers (the listed command is VO-"-").
- VO-Up Arrow or VO-Down Arrow: swipe up or down.
- VO-Command-Left Arrow or VO-Command-Right Arrow: adjust the rotor.
- VO-Command-Up Arrow or VO-Command-Down Arrow: adjust the setting specified by the rotor.
- VO-Shift-S: turn the screen curtain on or off.
- Escape: return to the previous screen.
- Command-Tab or Command-Shift-Tab: switch apps.

Text editing commands Apple lists (VoiceOver reads as the insertion point moves):

- Right Arrow or Left Arrow: character forward or back.
- Option-Right Arrow or Option-Left Arrow: word forward or back.
- Up Arrow or Down Arrow: up or down one line.
- Command-Up Arrow or Command-Down Arrow: top or bottom of the text field.
- Option-Up Arrow or Option-Down Arrow: Apple lists this both for beginning or end of a paragraph and for previous or next paragraph. Confirm the behavior on your Apple TV rather than assuming two different movements from the same keys.
- Shift plus a movement command: select text as you move.
- Command-A, Command-C, Command-X, Command-V: select all, copy, cut, paste.
- Command-Z or Shift-Command-Z: undo or redo.

Apple's table also listed "Go to the beginning or end of the line" as Command-Left Arrow or Command-Down Arrow. That pairing may be a typographical issue in the source table, because end-of-line is often Command-Right Arrow on Apple keyboards. This book does not "correct" it. Confirm line-edge movement with VoiceOver Help (VO-K) on your keyboard.


TROUBLESHOOTING
1. If speech stops, try a two-finger tap to unpause, then check volume on the TV, the remote, and Audio Channels in VoiceOver settings. Try VO-S on a keyboard if one is connected.
2. If movement seems wrong, two-finger triple-tap to switch navigation and exploration modes. Check whether the rotor is open (wait three seconds or swipe left or right to close it).
3. If swipes skip too many items in navigation mode, set Navigation Style to Follow Focus.
4. Press Menu or Back three times, or ask Siri, to toggle VoiceOver.
5. If the screen seems blank and a keyboard is connected, try VO-Shift-S for the screen curtain.
6. Use Settings > Accessibility > VoiceOver to reset speech rate, voice, and rotor contents to something you recognize.


PRACTICE EXERCISE
1. Open Settings > Accessibility > VoiceOver and listen through Navigation Style, Speech Rate, and Rotor.
2. During a show that offers audio descriptions, try the official AD settings path or the three-press clickpad shortcut while VoiceOver is on. Turn AD off again if you do not want it.
3. If you have a keyboard, press VO-K, try VO-E (mode switch) and VO-S, then exit Help and use one command for real.

Chapter 6.1. Getting Started with VoiceOver on Apple Vision Pro
============================================================

OVERVIEW
VoiceOver on Apple Vision Pro is a gesture-based screen reader for a spatial device. It speaks the name of the currently selected item, including icons and text, and it can also work with braille. You navigate and activate items with hand pinches, not with a glass touchscreen.

This part of SRTS: Screen Reader Training Suite is written carefully. Vision Pro gestures use named pinches such as "left index pinch." This book lists only gestures found in Apple's Vision Pro User Guide. If a gesture fails, use Settings > Accessibility > VoiceOver > Commands > All Commands on the device, because commands can be customized and handedness can be switched.

Important: VoiceOver changes the gestures you use to control Apple Vision Pro. When it is on, you must use VoiceOver gestures.


WHAT YOU'LL LEARN
- How Apple names pinch gestures.
- How to turn VoiceOver on or off.
- How to practice with the official tutorial and practice area.
- Why you should confirm commands on the device.


HOW PINCH GESTURES ARE NAMED
Apple describes four building blocks:

- Single-hand pinch: tap a finger and the thumb on the same hand together. "Left index pinch" means tap your left index finger and left thumb together. "Right ring double-pinch" means double-tap your right ring finger and thumb.
- Modifier pinch: hold a pinch on one hand while you pinch on the other. "Left ring modifier with right index pinch" means hold your left ring finger and thumb together, then tap your right index finger and thumb together.
- Long pinch: pinch and hold until the action is performed. "Right index long pinch" means pinch and hold the right index finger and right thumb.
- Slide pinch: a long pinch plus a movement. "Right index pinch swipe up" means pinch and hold the right index and thumb, move the hand upward, then release.

These names will feel long at first. They are precise, which is what you want on a device you cannot treat like a phone screen.


TURN VOICEOVER ON OR OFF
Use any official method:

- Ask Siri to "Turn on VoiceOver" or "Turn off VoiceOver."
- If you have set up the Accessibility Shortcut, triple-click the Digital Crown.
- Go to Settings, open Accessibility, open VoiceOver, and turn VoiceOver on or off.

Set the Accessibility Shortcut early, just as you would on iPhone.


PRACTICE AND THE TUTORIAL
When VoiceOver is on, you can follow a VoiceOver tutorial, and you can return to it later. You can also practice gestures without affecting settings or apps. When you practice, VoiceOver describes the gesture and the resulting action.

1. Go to Settings > Accessibility > VoiceOver.
2. Turn on VoiceOver if it is off.
3. Select VoiceOver Practice to try navigation, exploring what is in front of you, and scrolling, or select VoiceOver Tutorial if you are not sure how to use VoiceOver.
4. When you finish, select Done.

Apple also says the VoiceOver tutorial is a place to practice typing. Use these official practice tools before you pinch in an important app.


SEE OR CHANGE ALL COMMANDS
To get a list of all VoiceOver gestures, go to Settings > Accessibility > VoiceOver > Commands > All Commands.

You can switch the handedness of gestures by turning on Switch Gesture Handedness.

To add or change a gesture:

1. Go to Settings > Accessibility > VoiceOver > Commands.
2. Open All Commands, then open the command you want to update.
3. Select Add Gesture, then choose a gesture from the list.

To reset your changes, go to Commands and select Reset VoiceOver Commands.

Use this official list whenever this book and your device disagree. The device wins.


PRACTICE EXERCISE
1. Set the Accessibility Shortcut so a Digital Crown triple-click toggles VoiceOver.
2. Turn VoiceOver on with Siri or the shortcut.
3. Open VoiceOver Practice and try move-to-next, activate, and mute if those practice items are offered.
4. Open Commands > All Commands and listen to the mappings for activate, next, and previous, so you know whether they still match Apple's defaults in the next chapter.


QUICK REFERENCE SUMMARY
- Vision Pro VoiceOver uses named pinches: single-hand, modifier, long, and slide pinches.
- Turn VoiceOver on or off with Siri, a Digital Crown Accessibility Shortcut, or Settings > Accessibility > VoiceOver.
- Use VoiceOver Practice and the VoiceOver Tutorial before practicing in real apps.
- Confirm or customize every command in Settings > Accessibility > VoiceOver > Commands > All Commands.
- You can switch gesture handedness. Reset VoiceOver Commands if customization goes wrong.
- This book does not invent Vision Pro pinches.

Chapter 6.2. VoiceOver Gestures and the Rotor on Vision Pro
============================================================

OVERVIEW
This chapter lists default VoiceOver gestures from Apple's "Learn VoiceOver gestures on Apple Vision Pro" page, plus official rotor gestures. If you turned on Switch Gesture Handedness or assigned new gestures, your device will not match this list.

Apple also says you can explore by pinching and holding your right index finger and thumb. VoiceOver then speaks the name of each item you look at. You can also move through items in order from top to bottom and left to right with the next and previous pinches.


WHAT YOU'LL LEARN
- Default basic navigation gestures.
- Official reading, scrolling, and VoiceOver-control gestures.
- How to use the rotor with modifier pinches.
- How flat and grouped navigation change next and previous movement.


BASIC NAVIGATION GESTURES
Apple documents these defaults:

- Activate the selected item: left index pinch, or right ring pinch.
- Secondary activate: right ring quadruple pinch, or left index quadruple pinch.
- Move to the next item: right index pinch.
- Move to the previous item: right middle pinch.
- Long press: right ring double pinch, or left index double pinch.
- Begin passthrough gesture: right ring double long pinch, or left index double long pinch.
- Enter direct gesture mode: left index triple long pinch, or right ring triple long pinch.
- Escape: right middle long pinch.
- Magic tap: right ring triple pinch, or left index triple pinch.
- Switch to the next app: left ring modifier with right index pinch.
- Switch to the previous app: left ring modifier with right middle pinch.

Explore: pinch and hold the right index finger and thumb, and look at items. VoiceOver speaks each item you look at.

Secondary activate, passthrough, and direct gesture mode are official actions. This book does not invent extra meaning for them beyond Apple's names. If you need them, test them in VoiceOver Practice and check All Commands for any description your visionOS version provides.


READING GESTURES
- Read item summary: left ring pinch.
- Read all items from the top: right middle pinch and slide up.
- Read all from the current item: right middle pinch and slide down.
- Move to the previous item is also listed again in this official table as right middle pinch, which matches the navigation table.


SCROLLING
These official scroll gestures use the same opposite-direction idea you may know from iPhone three-finger swipes:

- Scroll up: right index pinch and slide down.
- Scroll down: right index pinch and slide up.
- Scroll left: right index pinch and slide right.
- Scroll right: right index pinch and slide left.


GESTURES THAT CONTROL VOICEOVER
- Mute or unmute VoiceOver speech: left middle pinch.
- Open the Item Chooser: left middle modifier with right ring pinch.
- Open VoiceOver Quick Settings: left index modifier with right ring pinch. Apple's settings page describes this the same way (a left index modifier and right ring pinch).
- Describe passthrough: left ring double pinch.
- Label item: left ring modifier with right ring pinch.
- Copy speech to clipboard: left middle double pinch.


USE THE ROTOR
Apple's rotor page says: when VoiceOver is on, hold your left middle finger and thumb, then use the next and previous gestures (right index pinch and right middle pinch) to move between rotor options. VoiceOver speaks the rotor setting.

To move between items in an option, such as speaking rate values, hold your left index finger and thumb, then use the next and previous gestures on your right hand.

The gestures page lists the same idea as:

- Choose a rotor setting, also called next or previous rotor: left middle modifier with right index pinch, or with right middle pinch.
- Move to the previous item or increase: left index modifier with right index pinch.
- Move to the next item or decrease: left index modifier with right middle pinch.

Customize the rotor in Settings > Accessibility > VoiceOver > Rotor, by choosing settings or dragging to reorder them. To have VoiceOver confirm rotor actions, go to Verbosity and turn on Speak Confirmation.

The rotor can include familiar ideas from iPhone, such as volume, speaking rate, and, as Apple's rotor intro says, special input methods such as Braille Screen Input or Handwriting. Confirm which items appear on your device.


FLAT OR GROUPED NAVIGATION
Go to Settings > Accessibility > VoiceOver > Navigation Style, then choose:

- Flat: next and previous (right index pinch and right middle pinch) move sequentially through each item in your view.
- Grouped: those same next and previous commands move through items and groups of items.

If movement skips a group of controls, check this setting before you assume a gesture is wrong.


PRACTICE EXERCISE
Do this in VoiceOver Practice first.

1. Use right index pinch and right middle pinch to move next and previous.
2. Use a left index pinch or right ring pinch to activate a practice item.
3. Mute and unmute with a left middle pinch.
4. Open the rotor with a left middle modifier plus a right index or right middle pinch, find speaking rate if it is there, and adjust it with the left index modifier plus right-hand next or previous.
5. Open All Commands and compare what you just practiced with the assigned gestures on your device.


QUICK REFERENCE SUMMARY
- Next: right index pinch. Previous: right middle pinch. Activate: left index pinch or right ring pinch.
- Escape: right middle long pinch. Magic Tap: right ring or left index triple pinch.
- Mute: left middle pinch. Item Chooser: left middle modifier plus right ring pinch. Quick Settings: left index modifier plus right ring pinch.
- Read from top: right middle pinch and slide up. Read from here: right middle pinch and slide down.
- Scroll uses right index pinch plus a slide in the opposite direction from the desired scroll.
- Rotor: left middle modifier plus right next or previous to choose a setting; left index modifier plus right next or previous to change the value.
- Confirm everything in All Commands if handedness or custom gestures are on.

Chapter 6.3. Typing, Settings, and Troubleshooting on Vision Pro

OVERVIEW
Typing on Apple Vision Pro with VoiceOver uses the virtual keyboard, dictation, rotor Typing Mode, and standard next, previous, and activate pinches. Settings cover audio, speech, verbosity, activities, navigation style, and Quick Settings. This chapter follows Apple's official pages and then gives recovery steps that only use documented gestures and shortcuts.


WHAT YOU'LL LEARN
- How to enter text with dictation, navigation pinches, or Typing Mode.
- Official typing feedback settings.
- Where to change volume, voice, verbosity, and activities.
- What to try if speech stops or gestures fail.


ENTER TEXT
1. Select a text field, then use a left index pinch, or a right ring pinch, to activate it. The insertion point and the virtual keyboard appear.
2. Enter text with one of the methods Apple documents:
   - Dictation: activate the Dictation control on the keyboard, then say what you want to type.
   - VoiceOver navigation gestures: use basic gestures, such as right middle pinch or right index pinch, to move among keys, and use a left index pinch to select a key.
   - Typing Mode: select Typing Mode in the rotor so focus moves to the virtual keyboard. Use the index finger on your dominant hand to point at keys, then tap your other index finger and thumb to select them.

Use the VoiceOver tutorial to practice typing, as Apple recommends.

This book does not invent additional virtual-keyboard layouts or assume iPhone Standard Typing and Touch Typing names are used on Vision Pro, except where Typing Mode is officially mentioned.


TYPING FEEDBACK SETTINGS
Go to Settings > Accessibility > VoiceOver, then use the official options:

- Phonetic Feedback, under Typing: speak a character, then its phonetic equivalent, such as "F" and then "foxtrot."
- Typing Feedback, under Typing: speak characters, words, both, or nothing.
- Rotor: choose which settings appear in the rotor, including, if you want, Typing Mode.
- Verbosity > Deleting Text: you can have deleted characters spoken in a lower pitch with Change Pitch.


VOLUME, VOICE, VERBOSITY, AND ACTIVITIES
- Volume: turn the Digital Crown. If the Digital Crown adjusts immersion instead of volume, press the Digital Crown first, then turn it, according to Apple.
- Other audio options, including VoiceOver Sounds and Audio Ducking, are in Settings > Accessibility > VoiceOver > Audio.
- Speaking rate is a slider in VoiceOver settings. Speech settings also include voice, enhanced-voice download if needed, pitch, pitch change, and pronunciations. Pronunciation dictation requires Enable Dictation in Settings > General > Keyboard.
- Verbosity includes hints, punctuation (including custom groups), uppercase letters, embedded links, rotor confirmation, and more.
- Activities can store settings and apply them automatically to apps or contexts, just as on iPhone. Create or edit an activity in Settings > Accessibility > VoiceOver > Activities.
- Quick Settings can be customized in Settings > Accessibility > VoiceOver > Quick Settings, and opened with a left index modifier plus a right ring pinch.

VoiceOver is not described here as a complete braille manual for Vision Pro. Apple's turn-on page says VoiceOver also gives descriptions in braille and can make a braille display more efficient. Use the Braille settings on the device and Apple's Vision Pro braille pages for those details, rather than assumed iPhone settings.


TROUBLESHOOTING
1. If speech stops, try a left middle pinch to unmute. Check Digital Crown volume, and check Audio Ducking or output if media is loud.
2. If you are lost, try a right middle long pinch for Escape, or open the Item Chooser with a left middle modifier plus a right ring pinch.
3. If the wrong gesture happens, open Commands > All Commands, or turn on VoiceOver Practice and identify what you pinched. Check Switch Gesture Handedness.
4. Triple-click the Digital Crown if the Accessibility Shortcut includes VoiceOver, or ask Siri to turn VoiceOver on or off.
5. Reset VoiceOver Commands if a custom mapping is the problem.
6. If you use a Magic Keyboard, Apple says you can use the rotor with the keyboard to adjust settings such as volume, speech rate, pitch or phonetics, typing echo, and punctuation. Confirm keyboard commands in All Commands or the official keyboard pages. Do not assume every iPhone VO shortcut is mapped identically until you check.


UNCERTAINTY YOU SHOULD EXPECT
visionOS changes, and pinch defaults can be customized. This edition may be incomplete on topics Apple documents outside the pages used here, including some braille, window management, and environment or passthrough details. When something is missing, use the on-device tutorial, All Commands, and Apple's current Vision Pro User Guide. That is the responsible way to use this part of the book.


PRACTICE EXERCISE
1. Open a text field in Notes or another simple app, activate it, and type a short word by moving among keys and selecting them.
2. Try dictation for a second short phrase, if Dictation is enabled.
3. Adjust speaking rate in Settings or with the rotor, and adjust volume with the Digital Crown (press it first if it is controlling immersion).
4. Practice mute (left middle pinch) and Escape (right middle long pinch), then the Accessibility Shortcut.


QUICK REFERENCE SUMMARY
- Activate a text field with a left index pinch or right ring pinch.
- Type by navigating keys and selecting them, by using rotor Typing Mode and pointing, or by dictation.
- Set phonetic and typing feedback in VoiceOver Typing settings.
- Digital Crown changes volume, but may need a press first if it is adjusting immersion.
- Mute: left middle pinch. Quick Settings: left index modifier plus right ring pinch. Escape: right middle long pinch.
- Recover with Siri, the Digital Crown shortcut, All Commands, and Reset VoiceOver Commands.
- Treat this Vision Pro part as a sourced introduction, and confirm details on the device.

Chapter 7.1. Helpful Accessible Apps
============================================================

OVERVIEW
Built-in Apple tools already cover a lot of daily seeing and reading work: VoiceOver, Magnifier, Live Recognition, Camera, Maps, and Safari Reader View. Third-party apps can still help, especially for describing a scene, reading a package, or calling a human volunteer.

This chapter describes a short list honestly, as of the research done for this SRTS: Screen Reader Training Suite edition in November 2026. Apps change, move, or shut down. Before you rely on one, confirm it is still in the App Store, still maintained, and still works with VoiceOver on your system version.

Do not use any seeing app, or any Apple recognition feature, as your only source of information in a situation where a mistake could cause harm, as a navigation system, or as medical advice. Apple makes that point for VoiceOver Recognition, and it applies here too.


WHAT YOU'LL LEARN
- Which built-in Apple tools to try first.
- An honest snapshot of Be My Eyes and Seeing AI.
- Why some well-known apps may not belong on an iPhone list.
- How to judge any new app with VoiceOver.


START WITH BUILT-IN APPLE TOOLS
Before you download something, make sure you can use:

- VoiceOver itself, including the rotor, Safari Reader View, and typing tools from Part 1.
- Magnifier, including Detection Mode if your iPhone offers it (Chapter 1.21).
- Live Recognition (four-finger triple tap, Chapter 1.21).
- Camera, which can describe objects in the viewfinder (Chapter 1.20).
- Maps, with the official VoiceOver tracking, zoom, and information-card features (Chapter 1.20).
- Screen Recognition and image text recognition in apps that lack labels (Chapter 1.22).
- The Phone, Messages, Mail, and Safari skills from earlier chapters.

These do not require a third-party account. They still have limits, and they still can be wrong.


BE MY EYES
Be My Eyes is a long-standing app that connects blind and low-vision users with sighted volunteers for a live video call, so a person can describe what is in front of your camera. The app also includes Be My AI, which describes a photo you take and lets you ask follow-up questions.

As of 2026, Be My Eyes documentation described Be My AI as available to iOS, Android, and Windows users, and said the apps are optimized for VoiceOver and TalkBack. You need an internet connection for Be My AI. An unstable connection can slow answers. Be My AI can describe pictures that contain faces, but the official help said it does not identify the people. In Illinois, face description was restricted for legal reasons at the time of that help article. Low light can be a problem; the help text said the flash may turn on, and that the app may ask you to retake the photo or, on iOS, consider calling a volunteer.

If AI is not good enough, call a volunteer. That human fallback is the main reason many people keep Be My Eyes installed even if they also use Apple's Live Recognition.

This book cannot promise wait times, volunteer quality, or future pricing. Check the app's current terms.


SEEING AI
Seeing AI is a Microsoft app designed with and for blind and low-vision people. It began on iPhone and later came to Android. It has offered tools such as reading short text in real time, capturing a printed document, describing a photo, scanning barcodes, recognizing currency, identifying colors, and sharing images from other apps for recognition.

In 2026, the app was still being updated on Android, including history, language, and "Ask Seeing AI" features. Because Microsoft has changed, moved, and combined accessibility tools over the years, confirm that Seeing AI is still offered in the App Store on your iPhone or iPad, and listen through its own tabs or menu rather than assuming this paragraph is a complete, current feature list.

Seeing AI has often included a mix of on-device and cloud features, depending on the mode. If you care about where a picture is sent, read the app's current privacy information.


APPS THIS BOOK WILL NOT OVERSELL
Google Lookout is a capable seeing app, but it is an Android app, not an iPhone app. This book mentions it only so you do not hunt for it on the App Store by mistake.

Other popular tools, such as some navigation apps, OCR readers, and money identifiers, come and go, change names, or become paid subscriptions. This edition does not print a long catalog that will be wrong six months later. If a teacher, a vocational rehab counselor, or a community such as AppleVis recommends an app, try it with VoiceOver and judge it yourself.


HOW TO TEST ANY NEW APP
1. Confirm that VoiceOver speaks the main buttons, and that you can start the primary task without a sighted assistant.
2. Try the Item Chooser (two-finger triple tap) if the screen is crowded.
3. If controls are unlabeled, try Screen Recognition for that app only (Chapter 1.22).
4. Test in a safe, familiar place first, especially for camera and navigation apps.
5. Check whether the app needs an account, a subscription, or constant internet access.
6. If the app is inaccessible and Screen Recognition does not help, do not struggle silently. Look for an alternative, or contact the developer with a precise VoiceOver bug report.


PRACTICE EXERCISE
1. Review Magnifier and Live Recognition on your iPhone if you have not already, so you know what you can do without another app.
2. If you want a volunteer backup, install Be My Eyes from the App Store, explore it with VoiceOver, and try Be My AI on a harmless object, such as a book cover. Optionally, learn where the volunteer call button is, without placing an unnecessary call.
3. Search the App Store for Seeing AI and, if it is still listed, open it and listen to its current modes. If it is not listed, do not install a similarly named unrelated app.
4. Uninstall anything you do not trust or cannot use.


QUICK REFERENCE SUMMARY
- Try Apple's built-in tools first: VoiceOver, Magnifier, Live Recognition, Camera, Maps, Safari Reader View, and Screen Recognition.
- Be My Eyes offers volunteer video calls and Be My AI photo descriptions. It needs internet for AI, and it may not identify faces. Check regional limits and current terms.
- Seeing AI is a Microsoft seeing app that has been important on iPhone for years. Confirm current App Store availability and features, because Microsoft's tools change.
- Lookout is Android-only.
- Test every new app with VoiceOver in a safe place, and do not rely on AI descriptions for safety, medicine, or navigation.

============================================================
VOICEOVER MASTERY: THE COMPLETE APPLE GUIDE
A book in SRTS: Screen Reader Training Suite
Part 7. Apps, Practice, and Sources
Chapter 7.2. A Practice Plan from Beginner to Power User
============================================================

OVERVIEW
This plan turns the book into a practice sequence. It is a suggestion, not a test. Spend more days on any step that still feels shaky. Skip a later platform chapter until you have the device in your hands.

The plan assumes iPhone is your first VoiceOver device. If you start on iPad or Mac, use the matching part, but still learn the shared ideas: move, activate, go back, pause, mute, Screen Curtain, and the rotor.


WHAT YOU'LL LEARN
- A beginner sequence for the first week.
- What "comfortable" means before you add power-user tools.
- How to add a second Apple device without starting over.


WEEK 1: GET ON, GET OFF, AND MOVE
Day 1. Turn VoiceOver on and off in Settings, with Siri, and with the Accessibility Shortcut (Chapter 1.1). Set the shortcut now.

Day 2. Use the VoiceOver Tutorial and VoiceOver Practice (Chapter 1.2). Practice swipe right, swipe left, double-tap, and a two-finger scrub until they are reliable.

Day 3. Explore the Home Screen, open and leave apps, and use the Item Chooser (Chapters 1.3 through 1.5).

Day 4. Learn mute and Screen Curtain, then immediately practice turning Screen Curtain off (Chapter 1.6). This is the day that prevents later panic.

Day 5. Practice Home, App Switcher, Control Center, and notifications for your iPhone model (Chapter 1.7).

Day 6. Learn the rotor. Use Speaking Rate and Headings (Chapter 1.8). Customize the rotor so those items are easy to find (Chapter 1.9).

Day 7. Rest, then repeat the gestures that still fail. Do not add typing yet if movement is still unreliable.


WEEK 2: TYPE, EDIT, AND COMMUNICATE
Days 8 and 9. Learn Standard Typing, then try Touch Typing if you want speed. Enable dictation if you want it (Chapters 1.10 and 1.12).

Day 10. Practice moving the insertion point and fixing a typo in Notes (Chapter 1.13).

Day 11. If you know braille, start Braille Screen Input in a note, not in an important message (Chapter 1.11). If you do not know braille, skip this day.

Day 12. Make a low-stakes Phone, Messages, and Mail practice: a message to yourself, a call you intend to end with Magic Tap (Chapter 1.18).

Day 13. Rearrange one app or learn Search from the Home Screen (Chapter 1.14). Adjust speaking rate and voice if needed (Chapter 1.15).

Day 14. Review troubleshooting once while everything still works (Chapter 1.25).


WEEK 3: THE WEB AND THE CAMERA
Days 15 and 16. Browse Safari by headings, links, and Reader View (Chapter 1.19).

Day 17. Try Maps in a familiar indoor or quiet outdoor place, not as street-crossing guidance (Chapter 1.20).

Day 18. Take a photo with Magic Tap and listen to Camera's viewfinder descriptions (Chapter 1.20).

Day 19. Try Live Recognition in a safe room, then turn it off (Chapter 1.21). Read the safety warning again.

Day 20. If you have a badly labeled app, try Screen Recognition for that app only (Chapter 1.22).

Days 21. Optional: connect a keyboard or a braille display (Chapters 1.23 and 1.24), or rest.


AFTER THE FIRST THREE WEEKS
Add power-user settings only when you feel the need: Activities, custom commands, custom labels, Quick Settings, punctuation groups (Chapters 1.16 and 1.17). Changing everything at once makes troubleshooting harder.

Then add other devices one at a time:

- iPad: Part 2, especially the Dock gesture and the two-tone versus three-tone system gestures.
- Mac: Part 3, starting with Command-F5, VO-arrows, VO-Space bar, and interact/exit. Do the official Mac tutorial.
- Apple Watch: Part 4, starting with the Digital Crown shortcut and the two-finger scrub.
- Apple TV: Part 5, starting with the Menu or Back triple-press and the two VoiceOver modes.
- Vision Pro: Part 6, starting with the official tutorial, All Commands, and next, previous, and activate pinches.

Chapter 7.1 can be added whenever you want a volunteer or OCR backup, after you already know Live Recognition and Magnifier.


WHAT "COMFORTABLE" MEANS
You do not need to memorize this whole book. You are comfortable when you can:

- Turn VoiceOver on and off without help.
- Move, activate, go back, and pause speech.
- Recover from mute and Screen Curtain.
- Use the rotor for speaking rate and at least one navigation type, such as headings.
- Type or dictate a short message, and fix a typo.
- Open Control Center or the equivalent on your device, and go Home.

Everything after that is speed and comfort, not a requirement.


PRACTICE EXERCISE
1. Circle, or note, which week you are actually in. Start there, not at the end of the book.

OVERVIEW
This chapter records how the book was researched, which system versions it targets, and where the author is less certain. If a later Apple update changes a gesture, believe your device and Apple's current user guide.


WHAT YOU'LL LEARN
- The target versions for this edition.
- The kinds of sources that were used.
- A plain list of accuracy uncertainties.
- How to report or work around a mismatch.


TARGET VERSIONS
This edition was written in November 2026.

- iPhone chapters target iOS 26, using the iPhone User Guide VoiceOver pages, including the iOS 26 path of "Operate iPhone when VoiceOver is on" when it was compared with the unversioned guide.
- iPad chapters target iPadOS 26, using the iPad User Guide.
- Mac chapters are based on Apple's VoiceOver User Guide for Mac as published in November 2026. The unversioned welcome page was labeled for macOS 27 at that time. Treat Mac commands as official for that guide, and confirm them on your Mac if you are still on an earlier macOS, or if Apple has revised a command.
- Apple Watch, Apple TV, and Apple Vision Pro chapters use Apple's then-current user guides and Support articles. watchOS, tvOS, and visionOS version numbers in those guides may not always be stated on every page.


WHAT WAS USED, AND WHAT WAS NOT
Sources are Apple User Guide pages and Apple Support articles, plus a small number of clearly identified third-party pages in Chapter 7.1 for app status. Each chapter lists its sources at the end.

This book does not invent gestures, rotor items, or keyboard shortcuts. If an official table was incomplete in the retrieved page, the missing shortcut was omitted or flagged, not guessed.

The book is not affiliated with Apple. Product names are Apple's trademarks.


ACCURACY UNCERTAINTIES
Please read these as warnings, not as hidden features.

iPhone and iOS versioning. Apple's unversioned iPhone User Guide, at the time of writing, mentioned hardware names and some Apple Intelligence features that were not in the iOS 26 "Operate iPhone" page, or that were footnoted for iOS 27. This book does not treat iPhone Duo Split View, or iOS 27 Apple Intelligence description features, as standard iOS 26 behavior. If your phone has those options, follow the device.

Icon-only official steps. Some Apple pages show buttons as icons, especially in Photos custom descriptions and a few Camera and Maps controls. This book tells you to explore labels and actions rather than inventing a button name.

Incomplete official keyboard tables. On iPhone, iPad, and Apple TV, a few rows in Apple's keyboard command tables were not clearly retrieved, including some Quick Nav letters and some text-movement shortcuts. Those were omitted. The Apple TV "beginning or end of the line" row looked inconsistent and is flagged in Chapter 5.3.

iPad windowed multitasking. Apple documents Full Screen Apps, Windowed Apps, and Stage Manager, and documents VoiceOver app switching, the Dock, and the App Switcher. A complete official VoiceOver gesture list for resizing windows or entering Split View was not found in the VoiceOver pages used for this edition. Chapter 2.4 therefore avoids invented window gestures.

Mac command breadth. Mac VoiceOver has large official command tables beyond the essentials in Part 3. Use the Commands menu and the VoiceOver User Guide on your Mac for interaction, orientation, search, and complete web and text commands. The Trackpad Commander name is common in the community; Apple's pages usually say "control VoiceOver with trackpad gestures."

Apple Watch close-control details. Some ways to close Control Center were not clearly stated as VoiceOver-specific in the retrieved pages. Follow what your watch speaks rather than a guessed close gesture. Keyboard options are officially unavailable on Apple Watch SE 3.

Apple TV 3rd generation and regional remotes. 3rd generation setup uses a different official sequence. Siri availability depends on language and region. Features vary by model.

Vision Pro completeness. Default pinch gestures and rotor modifiers in Part 6 come from Apple's Vision Pro User Guide. Custom commands, Switch Gesture Handedness, and later visionOS changes can make those defaults wrong on a given device. Braille, some environment or passthrough details, and some window actions may be documented by Apple in pages this edition did not fully incorporate. Confirm on-device in All Commands and the official guide.

Live Recognition and third-party apps. People, doors, and furniture detection require supported iPhone models. App features and availability, including Seeing AI in the App Store and Be My Eyes regional limits, can change after publication.

Restart button sequences. Hardware restart and force-restart combinations vary by model. Use Apple's official restart article for your exact device if the brief notes in Chapter 1.25 or 2.5 do not match.

Settings path wording. Some Settings screens are nested slightly differently across iOS versions, for example Rotor versus Rotor Items, or Typing versus Typing Style. Follow the labels you hear.


HOW TO HANDLE A MISMATCH
1. Use VoiceOver Practice, Keyboard Help, or the on-device Commands list to see what your system actually does.
2. Open Apple's current user guide for that device.
3. If you customized commands, reset only the commands, then retest before resetting all VoiceOver settings.
4. If you are using this book as a paid product and find a factual error, note the chapter, your device and system version, and what Apple's current page says, so a later edition can be corrected.


PRACTICE EXERCISE
1. Write down your device name and system version, for example "iPhone, iOS 26."
2. Skim the uncertainty list above and mark any that apply to you, such as a braille display, a Vision Pro, or a Bluetooth keyboard.
3. Bookmark, or favorite, Apple's VoiceOver user guide for your main device.


QUICK REFERENCE SUMMARY
- This edition was researched in November 2026. iPhone and iPad target iOS 26 and iPadOS 26. Mac content follows Apple's then-current VoiceOver User Guide, which was labeled for macOS 27.
- Official Apple documentation is the authority. This book cites it and does not invent commands.
- Known soft spots include later-iOS preview features, icon-only steps, incomplete keyboard tables, iPad window gestures, Mac command breadth, some Watch and tvOS edge cases, and Vision Pro customization.
- When in doubt, believe the device and Apple's current guide.
